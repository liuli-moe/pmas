# 危险课程 49

剧透：投票结果

- [x] "爱理，连一个星期都还没到呢。"
- [x] 她在重新培育一整个人。这本来就不可能又快又简单。这么短的时间内取得这么大的进展，已经远远超出了你的预期。
  - [x] 她不必独自承担这一切。我们可以想办法让其他爱优里的人也出一份力。
  - [x] 世界上有那么多魔法少女，还有各种擅长各种事情的人。如果她觉得需要什么——某个特定能力或专业知识什么的——只要开口，你就去找合适的人。
- [x] 不管怎样，这件事一定会成功的。你不会允许其他结果，你觉得爱理也不会。

你理解她的感受。

说实话，这并不复杂。挫败感太容易积累了，尤其是当你每天面对的都是看似毫无进展的现实。爱理只能*信任*你，因为她感知不到*你*能感知到的东西，而且你甚至不确定她是否真的相信你——相信确实*有什么*在发生。

你在努力给她希望，但她自己的怀疑在撕扯着她，试图把她拖入深渊。你很难责怪她，不是吗？

但你还是在努力帮她。综合来看，她甚至还没*做过*什么太过分的事。在一个从未发生过的时间线里，她本会毁掉昴宿圣团，制造一只合成魔女来推进她疯狂的复仇——但那是一个你已经彻底改写了的"从未发生"。在这里……

她偷了一颗净化之种。

这一点，你确定她做了，而且你也下定决心要在这件事上保持原则。

即便如此，你还是想帮她。毕竟是矫正而非惩罚。而且说到底，她也不过是另一个被孵化者精心策划的腐烂体制逼到崩溃边缘的、害怕的、孤独的魔法少女。她值得被帮助，就像帕罗和她的团伙一样——只不过你人在这里，而你觉得*你*能帮到爱理。

"爱理小姐，"你温柔地说。"连一个星期都还没到呢。"

爱理猛地靠回椅子上，抬起头用一种极度愤怒的眼神看着你，怒火在她眼中熊熊燃烧。

"那是对*你*来说，"她咬牙切齿地说，嘴角扭曲成一个冷笑。"对我来说，已经过了十七天又十六个小时，从我失去优里开始。*你*这辈子从没失去过任何东西吧？你根本*不知道*那是什么感觉！"

"你说得对，"你平静地说。"我没有。"

"那就*闭嘴！*"她怒吼道。"你根本不知道这种——这种*痛*是什么滋味！"

你抿紧了嘴唇，忍住了涌上来的烦躁，因为她*说得没错*。虽然你明白她的意思，但你并不真正*懂*。你从未失去过任何人，如果你能做主的话，以后也不会。早期那段时间麻美在边缘摇摇欲坠，就已经够糟糕的了。

她的眼泪开始涌上来，她愤怒地一下下抹着暗金色的眼睛，怒气坍塌成悲伤，她的灵魂宝石里翻涌着黑暗，你不允许那些悲叹继续积累。你*知道*她会拒绝肢体接触，但你还是忍不住凑了上去，离开椅子跪在她身旁，她把脸埋进了双手里。

你什么都没说。你和她还不够熟，不够亲近，提供不了比空话更多的东西。

但你至少可以待在这里，守着她。

于是你咬着舌头保持沉默，跪在爱理身旁，她压抑的啜泣声震颤着她的身体——难听的、急促的、拼命咽回去的哭声，她试图用一只手掌遮住，另一只手紧紧攥着那颗净化之种。至少她的灵魂宝石你能管——悲叹一形成你就立刻抽走。

最终，她的泪水干涸了，身体瘫软在原地，你一言不发地递给她一张纸巾——用一缕悲叹从她桌上的纸巾盒里抽出来的。她从你手里一把夺过，猛地擦了起来。

"你说得对，"你轻声说。"我没法想象你承受的痛苦，我真的，真的很抱歉。但……我想说的是，你在极短的时间里取得了惊人的进展。你在帮助一个人*重新回来*，爱理小姐——你在帮忙重新培育*一整个人*。这……这本来就不可能又快又简单。如果我打个响指就能搞定，我*早就*打了，但光是*现在*这些就已经远超我的预期了。"

"你是*这么说*，但我不知道——我*看*不到，我不*知道*这不是在——在白白*浪费时间*，"爱理哽咽着说。"这不*公平*，事情不应该——不应该*是这样*的！"

"……如果你*能*感知到我感知到的东西，会有帮助吗？"你缓缓地问。

爱理投来的目光充满了足以把墙皮腐蚀掉的恶意，仿佛你问了世界上最蠢的问题。这……好吧，想要某种具体的证据、某种可视化的进度指标确实是再正常不过的需求，但与此同时，那也意味着要直面净化之种可能*并未*苏醒的现实。你必须确认。

你坐回脚跟上，思考着。你本来就打算提出帮她找到需要的任何东西，而这显然*是*她想要的。

"我*也*可以试着把我的灵魂感知分享给你，"你缓缓地说。"但那需要借助我的*悲叹*操控能力，感觉会非常，呃，像魔女，而且我不确定实际上做不做得到。"

"我——不了，"爱理说着皱起了脸，摇了摇头，手微微颤抖着把净化之种拉得更近。

"那我想想别的办法，"你说。"我不觉得我能*教*你我的灵魂感知。它太内在了，跟我的愿望魔法紧密交织在一起，但外面有一整个世界的魔法少女呢。总会有一个女孩的灵魂感知能力是可以*分享*或者传授的。我会替你找到她。怎么样？"

或者也许你可以附魔制作某种可视化装置给她，或者类似的东西。

还有一整个心理咨询师团队，你在心里想着。希望小圆家的那位朋友能帮上忙，但他一个人肯定搞不定——光是爱荷华组的那些女孩就够他忙的了，更别说他自己原来的病人肯定也不能说扔就扔。

"走吧，薇，"爱理说，声音疲惫而空洞。连她的头发都好像无力地垂着，所有的精力都被抽空了。"我会继续弄的。有好消息了再来找我。"

你缓缓地呼出一口气。

"我……好吧，"你站起身说。"抱歉。不管怎样……这件事*一定*会成功的，无论如何。我不会允许其他结果。"

她把头转向另一边，不愿再多说什么。
