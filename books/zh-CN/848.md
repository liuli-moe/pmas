# 危险课程 36

剧透：投票结果

- [x] 两个女孩的动机都跟我们从羽翼身上观察到的不一致。你认为现在发生的事更像是一种机械性的运作，而不是非常强大的个人行为。律法的条文在精神缺位的情况下自行运转，或者另一个也在以类似的方式出问题。
- [x] 小心翼翼地在边缘试探，弄清规则是什么，然后从那里着手。
- [x] 除此之外，循环之理和另一个的基本理念都是宇宙无法被修复，只能推翻重来。无论羽翼的具体规则是什么，反击这个理念应该都很重要。
- [x] 所以就是你们基本的友情的魔法。向所有人证明——包括但不限于那两个人——我们能建设一个更好的世界。让每个人都参与到建设中来。基本上就是我们一直在做的事。

"友情的力量，"你自信地说，答案脱口而出。你咧嘴一笑，立刻举起双手。"等等，别跑，我是认真的。大部分是。听我说完。"

"嗯，"有希挑了挑眉。"我想我明白你的意思了——就像你说的，关键在于人，对吧？去说服她们别那么……危险。"

尽管你刚刚抛出了那么大的信息量，但关于小圆和焰的故事似乎反而没有最初的揭示那么让她不安了。她刻意放松了姿态，靠在沙发上。然而她的眼神依然锐利而专注，目光的力量几乎能物理性地把你钉在自己的座位上。

不只是她一个人盯着你，海香给你的眼神简直是如饥似渴，跟那股喜悦争相显露，双臂僵硬地夹在身侧，仿佛在物理性地克制自己不要爆发出一连串问题。说实话这有点让人担心，但……你信任和美。你信任她们关系的牢固程度，而且你信任和美知道什么是重要的。

织莉子和纪里香窝在她们自己的角落，织莉子皱着眉盯着天花板——天花板在你隔离结界的范围之外一片模糊。纪里香几乎蜷在她腿上了，看似毫不在意……但她的眼睛不时扫向你，即使织莉子沉浸在思绪中，她也保持着警觉。

"某种意义上说是的，"你说。"具体的我等下再说，但是……到目前为止羽翼的所作所为跟那两个女孩本身的*性格*对不上——跟她们任何一个的动机都不吻合。再加上这两个女孩显然*并不是*她们的升天形态，我认为正在发生的事情基本上更像是……*机械性*的运作。"

"所以才会'把事情拉回正轨'？"海香问，放下茶杯。

"对，"你说。"律法的条文在精神缺位的情况下自行运转，或者另一个也在以类似的方式出问题。大概是这样。"

"但看起来完全没有正常运作，如果魔女仍然存在的话，"有希审视着你说。"如果你是对的，那么在这方面似乎有什么东西彻底坏掉了。所以我们看到的可以认为是……*误导性的*尝试。"

"我得说神一般的力量却没有任何人操控，这个想法可不怎么令人安心，"织莉子探身拿了块饼干，掰成两半跟纪里香分享时干巴巴地评论道。

"哦是啊，"你叹气说。"我需要……在边缘小心试探来弄清楚规则是什么。"

"*你*去？"有希尖锐地问。

"我……对，我去，"你苦着脸说。你冲麻美投去一个歉意的微笑。"这不是……"你叹了口气。"我在调查的时候肯定会找人帮忙看着，但我……唉。不是我不愿意分享我知道的，就是*唉*。分享这些知识是*危险的*，而且这本来*不是我的秘密*，这就意味着*我*才是那个知道该往哪里戳的人，也就意味着这件事必须由我来牵头。"

麻美的手在你手中紧了一瞬。你大概得让她放心你做那些实验的时候会小心，考虑到上次她发现你在做那种实验时的反应。但当你对上她的目光时，你看到蜜金色的眼底有担忧在游动……但也有坚定。她微微歪头，无声地表示*回头再说*，然后微笑了，小但真实。

"我想说的是，既然我们都牵涉其中，这些信息对我们来说*是*相关的，"有希说。

"我能说的基本都说了，"你抱歉地说。"对不起，相信我，如果不会辜负其他人对我的信任的话，我*绝对*会把所有事情全部告诉你们。只是……这是关于*她们*的事，你懂吗？我就是……就像我说的，忘掉那些……改写现实的女神之类的部分。到最后，那些都不是真正重要的。重要的是两个受过创伤的女孩，我想帮助她们，仅此而已。其他的不过是布景板。"

"'关键在于人'，"有希引述道，表情中性，身体前倾，双手从斗篷中探出支在膝盖上，目光如锥般紧紧钉着你。"我不能说我喜欢这样。你积累了足够的信誉让我选择信任你，但……"她抿了抿嘴。"我要提一个硬性条件，你必须及时向我通报任何相关的进展。我不觉得这是过分的要求——而且我坚持你也要通知中野小姐，以及渡边小姐和齐藤小姐。我理解你确实是在得到确认后*就*分享给我们了，但如果大家互相藏着秘密的话，联盟就不像联盟了。"

"……嗯，这太合理了，"你点头说。"那就这样，我会尽全力让大家及时了解进展和状况。"

"那目前就到这里吧，"有希的表情平缓下来，重新靠回沙发，顺手端起了茶杯。

"所以……嗯，"你说。"我会牵头，同时让大家保持信息同步。如果我需要帮忙，不管是需要人帮忙看着还是需要不同的魔法，我会开口。如果我发现什么重要的，或者有什么事发生了，我会通知大家。"你抿了抿嘴。"我……真的需要依赖你的领地传送来出行，鹤屋小姐。"

"没问题，"有希说。"而且如果你不介意我说一句，你的能力*确实*看起来很……跟律法相关，"有希沉吟道。"你的魔法毕竟有着独一无二的摧毁魔女的能力。也许我在妄下结论，但我注意到你*确实*有翅膀，就像你说的那两个女孩在升天形态中有的那样。"

"……是啊，其实我本来也打算提的，"你说。"我的翅膀是……这么说吧，我*以为*它们只是我魔法的一个侧面，'只是'一项我掌握的特定技术，就像所有魔法少女都有很多本能的技巧一样，对吧？"众人点头表示同意。"嗯……最近，我们在一个似乎能展现灵魂的魔女结界里，我的翅膀*不是*魔法性质的，它们是……我其实也不确定，但即使不付出任何努力，它们就*在那里*。"

有希*看*了你一眼，织莉子也以一种奇妙的同步给了你同样的眼神。

"你从来不像那种自我膨胀的人，所以……我不会质疑你，"有希片刻后说。"但你应该意识到那听起来是什么样的。"

"是，我知道，"你说。一个关于女神的故事，而且基本上只有*你*能验证，然后还有你跟她们的关联？哦是的，你当然明白有希的意思。所以你对她点头致意，但坦然地迎视她的目光。"我能说的只是，既然我从织莉子和御崎小姐的魔法那里得到了确认，我不想再继续瞒着你们了。"

麻美握了握你的手，从你肩上直起身来，以一个温和而坚定的微笑引来了众人的注意。

"在我看来，这些揭示在*实际操作层面*暂时并没有改变我们太多，"她说。"我们还是在朝着同样的目标合作。我们多了一个需要留意的额外目标，没错，但这个目标暂时除了萨布丽娜之外——也许还有美国小姐——并不需要任何人额外付出什么。我说得对吗？"

"以及一个可能彻底偷袭我们的极端危险威胁，"有希指出。"但我理解你的意思。它一直都在，只是我现在知道它的存在了。"

"我想说的一点是，循环之理和它的对立面，两者的前提都是需要*重写*宇宙，"你说。"而我*非常非常*反对这个。我对我在这里建立的生活很满意，你懂吗？但这里的关键是……一步一步让世界变得更好，证明世界*可以*变得更好？星座联盟的理念*本身就是*对那种理念的抗争。"

"说得好！"海香愉快地说。"我们绝对支持你，萨布丽娜小姐，而且我*确定*和美也一样。"

"不多也不少，正是我们的宪章所述，"有希若有所思。她点点头。"也就是说，我们本来就在做的事。"

"我搞不懂你为啥那么担心，"纪里香突然冒出一句，边拍掉衬衫上的饼干碎屑边坐直身子。"好嘛，也许我们有两个魔法少女女神在吵架，但这不就意味着我们得把她们拖去做关系咨询嘛。因为她们是女神所以拖起来*稍微*费劲点，但*重要*的部分又不复杂。"

"……我很不满这个比喻居然说得通，"你伸出一根手指指着她。

"因为我说的*对*啊，"她说。那个冲着你的咧嘴笑完全不被你的指头所动摇，她的小虎牙只会让那份得意更加醒目。

"因为你说的对，"你同意。"这*确实*基本上准确概括了我的计划。但你漏了一个重要的部分：我们*没有*关系咨询师。"

"有啊！"纪里香拇指一点自己。"在这儿呢！我*可*懂爱了。不过实在不行，我*勉强*承认你也许也能做得还行吧。"

"我们完蛋了，"你说。

这至少引来了一阵大笑，还有纪里香的不满。话说回来，纪里香基本上是对的。这确实关乎小圆和焰，以及她们之间的关系。循环之理本身还有个支线要处理，让人们不再变成魔女确实重要，但*最*重要的是要确保有一种方式能实现这个目标，而不需要小圆永久地从世界上消失。

"那么，"有希说。"我可以说我大体上安心了——"一个朝你投来的笑——"关于我们的末日。"

"那太好了，"你说着竭力不让自己看起来*太*如释重负，端起茶杯抿了一口来掩饰。"我会把其他人也带入循环，尽快给大家一些更具体的东西。"

有希点头。

"如果你跟中野小姐谈话时需要支援就告诉我，"她说。"渡边小姐和齐藤小姐也一样。"

"会的。而且……"你说着看了一眼手机上的时间。"唉，我本来还有些问题想通过御崎小姐的能力来问，我觉得你也有吧，织莉子？但我们时间有点不够了，因为跑题了不少，而且我们得尽快赶回见泷原赶上午餐。不过……好吧。御崎小姐，鹤屋小姐，我是否充分回应了你们关于整个……羽翼事件的顾虑？"

"充分了，"有希点头说。

"随时欢迎你回来问更多问题，"海香说。"本来想把羽翼笔借你一支，但它们掉魔力掉得很快。"

"……有多快？"你问。

"如果我不在附近维持供能的话，不到一个小时，"海香说着露出一个眷恋的微笑。"相信我，我们试过了——妮可想给我们所有人做魔法装备，不让我们测试她的魔法跟我的魔法结合的效果她就不肯罢休。"

"啊，那可惜了，"你说。"那么……谢谢你今天的招待，御崎小姐。"

"不，谢谢*你*，"她说，一个大大的笑容打破了她的矜持。"你给了我*太多*思考的素材了。"

"……呃……"你犹豫着，试图找到合适的措辞来温和地提醒她别太沉迷于叙事的兴奋感。

"放心，我记得你说的关于保密的事，"她说。"我只是……"她满足地叹了口气，推了推眼镜。"我就是喜欢好故事嘛，你懂的？"

"啊，"你说。"那好吧。谢谢你。"

"不，谢谢*你*，"她说着笑容更灿了。

你笑了。

"不管怎样，那我去找和美，看看你朋友，呃，佐仓小姐跟她聊完了没有？"海香说。"既然你们准备走了。"

"那就拜托了，"你说。

"好！那回头见啦，"海香说着站起来朝外走，在隐私结界的模糊边缘犹豫了一瞬，然后迈了出去。

你俯身捡起隐私结界，准备撤掉它，麻美却轻轻推了你一下，阻止了你。

"萨布丽娜，我有个问题？"她说，目光扫过在场的其他朋友。"如果大家不介意的话，我想私下问？"

"*噢*，"纪里香说着已经弹了起来，拽着织莉子一同站起。"听起来很重要！走吧，织莉子！"

织莉子笑了笑，向麻美微微颔首，以一种从容得多的步调起身，优雅地飘出了隐私结界，毫无怨言——只不过这份优雅被纪里香临走时冲到桌边抓了一小摞小熊形饼干的举动给破坏了。同样的，有希向你点了点头就毫无异议地离开了隔离区，跨步跟上织莉子和纪里香，看样子是要找她们谈话。

于是隐私结界模糊灰暗的范围内只剩下了你和麻美，外面的世界变得沉闷朦胧，但麻美正微笑着看着你，你的手握在她的手中。

"是小圆和焰吧？"她问。
