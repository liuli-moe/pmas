# 危险课程 42

剧透：投票结果（续）

  - [x] 怎么应对焰的恐惧？
    - [x] 问问焰以前有没有试过告诉小圆这件事。我们觉得她没有，但应该确认一下。
    - [x] 焰知道小圆是个无私的人。对她自己的威胁不如对其他人的威胁更能让小圆有所触动。
    - [x] 我们不用揭露巫妖炸弹就能告诉她这个风险，可以把它解释为小圆特有的风险。
    - [x] 如果焰还没准备好谈那件事，我们不用透露时间循环的事，可以说这是萨布丽娜的元知识。

你让焰慢慢平复，沉默蔓延开来的时候仍然握着她的手。她刚刚给了你的绝非小事，而你接下来要请求她的更为重大。但即便如此，你感到了些许宽慰，肩上的重担轻了一些。

小圆相信她的朋友们。你知道这是事实：即使胸怀着要让自己的人生有所作为的驱动力，即使背负着*确切地*知道自己可以如何改变局面的*重压*，只要朋友们开口请求，她愿意让她们来处理。她愿意*等*，只要还有人在做*些什么*。

只要你还在，只要焰、麻美和沙耶香还在，你不觉得事情会走到小圆许愿那一步。正如你向焰保证的，你会竭尽全力阻止。但*如果*。

*如果*。

*如果*真到了那一步，你现在多了一张牌可打。让小圆知道代价是什么，让她知道焰有多爱她，那样做会让焰多么痛苦。小圆会听的，你*知道*她会。你不知道这些牌打出去会怎样，事情会如何发展，小圆最终会做什么决定……但这是*你*手中多出的一张牌。

但那是以后的事。此刻，你把注意力放在焰身上，轻轻捏着她的手提醒她不是一个人。你会替她扛下所有能扛的，但只有她自己才能打赢心中的那些仗。

"你觉得……"焰的声音说到一半就断了，下巴紧咬着无声地摇了摇头。但你知道她想问什么。写在她紧绷的肩膀上，写在她的目光从你身上移到楼梯间、再到你们交握的手上的方式中——那几不可察的颤抖。

"说实话，我没法百分之百保证，"你坦承。"我又不会预知未来，对吧？但我*会*竭尽所能阻止她*身处*那种觉得自己*不得不*许愿的情境。而且也不是只有我们在做这件事，对吧？我们还有朋友们帮忙。她们不完全了解事情的厉害关系，但她们清楚愿望会带来一些……相当沉重的代价。"

焰僵硬地点了点头，你闭上嘴，让她消化。与其打破沉默，你用拇指轻轻指了指她的灵魂宝石示意，在她点头后抹去了正在聚集的悲叹，她的肩膀几乎不可见地放松了一些。又过了几分钟，她才重新抬眼与你对视。

"……你还有什么别的想法吗？"她安静地问。

"有，"你说。"这个……要求比较大，但跟之前一样：没有你的许可就不会做。好吗？"

你直视她的双眼直到她点头。因为你不想*逼迫*焰接受：你是在*请求*她的许可，不是想强行让她同意。也许你太谨慎了，太迟疑了，也许你把话说得太绕了，但这是*焰*。沙耶香说过她是你最好的朋友，这话还真没说错，是吧？

"好，"你吐出一口气说。"我……我想请求你的许可，现在就告诉小圆，如果她签约，她可能会毁灭世界。"

一声急促的吸气。

"*不行*，"焰脱口而出，双手用令人瘀青的力道紧扣住你的手，脸上的表情像雕刻的石头般冻结。"我——*不行*。"

电光火石的抉择。你在脑中飞速梳理自己的逻辑，思维如瀑布般倾泻而下：也许焰以前没试过这样做。这会让小圆停下手。这当然是一个*强有力的*论据来阻止小圆签约，而且她会听从。毕竟她一直愿意为了他人牺牲*自己*；一想到会伤害到如此、如此多的人——不只是焰——绝对会把签约这个念头在小圆愿意付诸行动的事项清单上压得*非常非常*靠后。你甚至不用透露焰的时间循环就能做到。你可以说成是你自己的那些奇怪的知识，小圆会接受的。

不够。

面对那个崩溃的表情，不够。面对焰这样*碎裂*，不够。面对一脚踩进焰的恐惧和创伤的正中央，踩进那个焰最最惧怕的最坏情境，不够。

因为创伤不是理性的。

而你手里只有理性的论据。

"那我不会这么做，"你简单地说。"我要的是*你*的许可，焰，你不同意，所以我不会。"

也许你逼得太紧、太猛、太急了。也许让焰去思考最坏的情况，让焰去*设想*小圆可能许愿然后魔女化的场景，已经太过了。也许如果你给焰更多的*时间*，也许如果有什么更好的安慰方式。说"不会走到那一步的"、"我们正在取得进展"之类的安慰话，在*亲眼目睹*小圆一次、又一次、又一次坠落之后，能起的作用毕竟有限。

"焰，我要抱你一下，好吗？"你说着等她那僵硬的点头，然后轻轻将她拉入怀中。她一只手仍然抓着你的手，你的骨头在她的握力下嘎吱作响，身体却虚软地挂在你的臂弯里，但没关系。你当然盯着她的灵魂宝石，追踪悲叹的渗出。

问题在于……

问题在于，这也许是焰自那命运般的第三次循环以来与小圆最接近的一次。理性来看，你只不过是在请求告诉小圆一些事情。但*非理性*地看，你想，焰记得*发生过什么*，而她只是……完全无法接受这个想法。即使你不*能理解*，你还是理解。

也许有更好的方式来提起这个话题，但不是现在。不是今天。

现在重要的是确保焰没事。所以你就这样待着，轻轻拍着她的背，咬住了想道歉的冲动。你不敢说自己完美，*差远了*，尤其是现在，但你*可以*陪在她身边，不在她试图恢复平静的时候喋喋不休。希望这就够了。

"不会发生的，"你低语。你不确定自己说的是小圆签约这件事、还是小圆魔女化、还是只是*告诉*她这件事，也许三者兼有，但你是认真的。

焰长长地、颤抖地吸了一口气，点了点头，从你怀中退开。

"不着急，"你温柔地鼓励着，对她微笑。"我在这里，我们不赶时间，好吗？"

"我——没事，"她低头嘟囔。"我——我相信你。"

"谢谢你，"你说。她还没有松开那死死的握力，但你忽略这一点，把另一只空闲的手覆在她手上轻轻捏了捏。"让你这么痛苦，我很抱歉，焰。"

她无声地摇头，拒绝了你的道歉。

"*你*的幸福和健康也很重要，"你安静地说。"对小圆来说很重要。你知道这是事实。对我来说很重要，对麻美、对沙耶香、对仁美都很重要。*你*很重要。我……有我的理由，才会提出那些，而且……*也许*我们改天可以再谈，如果你觉得可以的话。但*你*很重要，焰。让你受伤了，我很抱歉。"

焰咽了一下。然后，缓缓地，她点了点头。

你会把这当作进步。你让对话再次沉寂，不觉得有填充空气的必要，只是看着焰在时间停止的灰暗色调中重新整理自己，用了好几分钟。紧张感在消退，但始终没有完全离开她肩膀和眼角的线条。不过她的呼吸平稳了下来，目光重新抬起与你对视，下颌绷紧，仿佛在准备迎接什么。

"接下来呢？"她安静地问。

"没了，"你微笑着说。"这次就想说这些。"

你本来有念头想*现在*就把魔女的真正起源告诉仁美，你还是有点想这么做，但你不想让焰承受更多压力。你会找时间单独跟仁美说的，也许今晚。而且说实话，告诉仁美*那件事*然后就把她赶去上课，好像也不太厚道。

焰久久地看着你，审视你的表情，然后又一次点头。

"好，"她低声说。"谢谢你。"

"不过呃，还有*一件事*，"你不好意思地笑着说，赶在她开始绷紧之前继续。"呃，你能放开我的手吗？"

焰一抖，目光猛地落到你的手上，痉挛般地松开了。血液涌回你的手指时你龇了龇牙，活动着手指，骨头咔咔作响。

"……抱歉，"焰低下头嘟囔。

"是我自己造成的，"你说。但当你轻轻拍她肩膀的时候，用的是*另一只*手。"你感觉怎么样，焰？"

"累了，"她说。

"嗯，这……是的，"你叹了口气。身心俱疲，虽然焰不会用这种说法。"不着急。"

她苦笑着摇头，目光从你身上移开，落在麻美凝固的身影上，停留了很久。

"你变了好多，"她安静地低语。"这……是好事。情况在好转。但……"

"不确定性？"你问。

她点头。

"欢迎加入，"你歪嘴一笑。"我也很担心，经常担心。我能做的就是尽自己所能，把注意力放在重要的事情上。我们的朋友们，还有我们的目标。这就是我们任何人能做的一切了。我……"你笑着摇头。"又不是说我什么答案都有。我有不同的视角，嗯，还有魔法来支撑。这些是优势，但也仅此而已。不是什么一键通关按钮之类的。"

"……好，"焰说。不知怎的，她似乎因为这个回答松了口气，肩膀上的一些紧张消散了。"我……很高兴你在这里。"

"我也很高兴自己在这里，"你说着，笑容变得更自然了。"谢谢你，焰。而且……嗯，我不敢说自己完美。但我会继续尽我所能。"

又一个沉稳的点头，焰深吸一口气，站了起来。

"我该回到小圆身边了，"她说。

"确定你没事吗？"你站起来时仔细打量她。

"嗯，"她说。

"那回头见，焰，"你微笑着刻意后退一步，让你的悲叹雾脱离与焰——

——的接触。

你呼出一口气，城市的喧嚣因骤然回归而格外响亮。正午的太阳在头顶灼灼照耀，倾泻而下的暖意堪比麻美迎接你的灿烂笑容，你也对她绽开笑脸。

"谈得怎么样？"她问。

"有好有坏，但总体来说不错吧，"你张开双臂回答。"有些事情需要之后跟进，不过这是常态了。"

"嗯哼，"麻美微笑着走过来接受你无声的邀请，钻进你的怀抱。"那，接下来做什么，萨布丽娜？"
