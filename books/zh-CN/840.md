# 危险课程 28

剧透：投票结果

- [x] 跟焰和仁美谈谈给有希买栋楼的事
- [x] 提一下美香想见面的事
- [x] 快速收尾之前的话题：
  - [x] 你计划明天去京都和九州，跟紫社巫女和鹿儿岛组接触。有人要带话或者随行吗？
  - [x] 提一下你*确实*在东北大学和立正大学有联系人，可以找法学生。
- [x] 离开前跟沙耶香谈谈
- [x] 织莉子有事想谈
- [x] 把双子送到盐竈组那里
- [x] 把受害者的收藏飞到妮可那里
  - [x] 顺路接上有希，飞回见泷原，让她去找栋楼，同时你去订一批酒店房间

你想了一秒，盯着有希的肖像。你觉得有希和仁美见面没什么问题，所以真正需要考虑的只是实际操作。说到实际操作，你不得不把思绪从月球基地的后勤规划中硬拽回来。

你*比较*确定有希能将建筑虫洞连接设置为被动效果，考虑到之前切磋时她搞出的那个"一罐阳光"的把戏。你*也*记得当时把你从翌桧市送回福岛是一个主动行为，她需要施加意志来完成，所以……也许是她能力的两个层级，投入的精力和消耗各不相同。你挺希望能说服她给假设中的月球基地建立一条持续连接，光是供氧就会方便太多。

……不，先回来，还有更重要的事。你手上有一场即将发生的难民危机。虽然严格来说，难民危机得等你把她们从昏迷中救出来*之后*才算。好吧。

"*面对面的话，还是心灵感应就够了？*"你想了一下后问。"*我打算一会儿就去找焰和仁美，不过我*今天*是要飞你过来见泷原的，对吧？虽然仁美*现在*在上学。她应该愿意先通过心灵感应聊。*"

"*啊，当然，*"有希说。"*面对面更好，我可以等到下午。只要你不介意我在见泷原待一阵子。*"

"*应该没问题？*"你说，瞥向麻美和沙耶香，两人都耸了耸肩。你一会儿跟焰确认一下。"*好，那暂定方案：我们先把这边的事结束，然后我出发去你那里，鹤屋小姐，走捷径到翌桧市把双子的受害者送过去。回程的时候接上你，鹤屋小姐。大家觉得行吗？*"

"*完全没问题，*"有希说。

"*你大概什么时候到？*"和美问。

"*算算……*"你看了看织莉子，又看了看沙耶香。余光里杏子慢慢坐直了身子，皱着眉看向美国宅邸窗外阴沉的天空。"*就……这个会结束后一个小时？*"

"*好！*"和美开朗地说。"*要不要留下来吃午饭？其实所有想来的人都可以一起吃！*"

"*不巧我们已经有午餐约了，*"麻美歉意地说。"*下次吧，和美？*"

"*啊，好吧。没关系，*"和美说。"*不过随时欢迎来哦！*"

"*找个时间一定去，*"你说，冲麻美微笑。这倒是把今天的时间表理得很清楚了。"*好。大家都同意这个方案的话？*"

"*我能下午去一趟见泷原吗？*"美香问。"*想跟鹤屋小姐和志筑小姐一起聊聊。应该还有晓美小姐？*"

"*这……应该可以？*"你说。"*我去跟仁美说一声，然后告诉你和鹤屋小姐。我不觉得她会不同意。*"

"*那拜托了，*"美香说。

"*好。等一下？*"你说，把那条连接暂时压到意识后方，再次伸出心灵感应。"*焰，仁美。你们还好吗？*"

"*啊，萨布丽娜？*"仁美听起来有些惊讶。"*这个时间找我倒是不多见。出什么事了？*"

"*你需要……什么吗？*"焰素来果断直接，这次说话却犹豫了一下。你仿佛看到她在教室里瞥了一眼仁美。"*麻美没事吧？*"

"*哦！一切都好，不用担心，*"你说。"*两个问题——第一，你们给鹤屋小姐安排的房子进度怎么样了？如果短期内搞不定的话，我可以先找个临时的，反正之后搬迁据点也不难。*"

"*地点已经选好了，*"焰低声说。"*手续比较费时间。*"

"*……如果紧急的话，我*可以*加急处理，今天之内拿到文件，前提是你或者焰能帮忙，*"仁美说。"*我自己掏腰包的话不够，而且负责那片区域的中介不是前端控股旗下的。*"

"*哦，行，可能需要费点功夫，但应该可以，*"你说。

"*不用那样，*"焰说。你仿佛看到紫色的眼睛微微眯起，带着熟悉的无奈朝你投来。"*我来跟仁美配合。*"

"*哦，*"你眨了眨眼，忍住窃笑——那件事还在进行中呢？"*好吧，那就这么定了……你确定的话。*"

"*我确定，*"焰说。

"*那我们午饭的时候处理这事，*"仁美说。"*你不是说有两个问题吗？*"

"*对，虽然不该用'问题'这个词，*"你说。"*嗯。如果可以的话，中野小姐和鹤屋小姐想在今天放学后见你，仁美。心灵感应也行。*"

你设法向焰传达了一个眼神和扬起的眉毛。因为你想让她知道，也想征得她的同意——虽说你不是带外面的魔法少女来见小圆，但如果她反对的话，你也不会一意孤行。你可能会跟她讨论，但……焰的意见很重要。

"*哦。哦！好的，我一直很期待见中野小姐，谢谢，*"仁美说，心灵声音亮了起来。"*没想到这么快，不过完全没问题。鹤屋小姐跟我见面是谈同一件事，还是另外的？*"

"*听起来……挺有意思的，*"焰中性地说，一缕放松的感觉化开了，你肩头那丝隐隐的担忧消散了。你没觉得她会反对，特别是美香和有希都已经答应跟你一起面对魔女之夜了，但得到确认还是好的。

麻美好奇地瞥了你一眼，然后微笑着拉起你的手，用双手握住，手指沿着你的掌心轻轻描画。

"*另外的，*"你说，回应仁美而不是去表达心里的那些。"*嗯，大部分是。午饭的时候再跟你说？*"

"*好的，*"仁美说，语气里带着兴奋。"*这可真*有意思*了。*"

"*那就希望不辜负你的期望咯！*"你说。"*午饭见！替我跟小圆问好。*"

"*没问题，*"仁美答应道。

你对自己微笑着，把注意力转回会议。

"*……不应该局限在东亚，*"有希辩论道。"*我们基本上都会说英语吧？向英语国家拓展是应该考虑的，而且我们不能什么事都指望薇小姐一个人去做。*"

你眨了眨眼，回顾了一下你只听了一半的对话……啊，在讨论拓展的事。

"*这……倒也是，*"纪子让步了。"*不过没有薇小姐飞我们过去的话，去英语国家也不容易，除非……中野小姐能载人？*"

"*能倒是能，但我宁可掏机票钱，*"美香说。"*那样更简单。*"

"*……哦。对，我忘了，呃，飞机这种东西，*"纪子说，不好意思地红了脸。明美咯咯笑着，一只手搭在纪子的肩上，把两个身体都搂了过去。"*……嗯，那听起来挺可行的？*"

"*鹤屋小姐，你有什么具体人选吗？*"你问。

"*暂时没有，*"有希说。"*但我打算去了解一下。你那边的朋友们有什么消息吗？*"

"*说得也是。那，呃……鹤屋小姐、中野小姐，仁美很乐意今天放学后见你们，*"你说。"*而且仁美觉得今天之内就能把公寓的手续办好，所以你今天就能建立据点了？*"

"*啊，很好，*"有希满意地说。"*那我期待着。*"

"*放学了告诉我一声，我就过去！*"美香开朗地说。

"*好，*"你说。"*对了，说到拓展什么的——我*打算*明天去京都和九州，跟紫社巫女和鹿儿岛组接触一下。有人要随行或者带话吗？*"

"*如果她们表示愿意让我在那里建立据点的话，我当然很乐意同行，*"有希说。"*另外……我确实说过有兴趣见见她们，不过你知道紫社那些人是真的巫女，还是只是这么叫自己的？*"

"*我……不知道，抱歉，*"你说。"*但据我所知至少不是*全部*都是。*"

"*嗯。如果她们是的话，我想知道，还有……*"有希沉吟了一下。"*能否帮我问问她们愿不愿意分享御神酒？*"

你眨了眨眼。御神酒……也就是供奉用的神酒。

"*……行，我问问？*"你说。"*要我给她们什么理由吗？*"

"*我……不太确定自己酿造的方法是否正确，*"有希坦承。"*所以一直忽略了这方面。*"

"*鹤屋小姐，你是巫女吗？*"由麻屏着呼吸，急切地脱口问出了大概所有人心里的问题。

"*我不是，*"有希平静地说。她大概预料到了这个问题。"*但我也是唯一一个在照看神社的人，所以只能尽力而为了。*"

"*哦！*"由麻恍然大悟地点头。"*我明白了！*"

"*我看看能做什么，*"你说。"*然后嘛……我还应该提一下我在东北大学和立正大学有些联系人，也许能找到一些法学生帮忙，不过……嗯。这事先放一放？所以，还有别的吗？*"

"*别的没什么重要的了，不过我再强调一下，如果我们决定走那条路的话，我*是*认真愿意帮忙找几个律师来的，*"美香说。"*除此之外，今天下午见泷原见。*"

一连串的"没了"跟在美香后面，你点了点头。

"*那……就这样了，*"你说。"*谢谢大家今天参加。*"

"*谢*你*！*"和美开开心心地说。"*好期待再见到你。回头见！*"

会议就此结束，你微笑着看着连接断开，望向你的朋友们。麻美对上你的目光微微一笑，靠在你身边，你在沙发上伸了个懒腰，顺便瞥了一眼那对双生灵魂宝石，悬浮在你面前。你最新的所有麻烦的源头，但……结果还算满意吧。飞到福岛再到翌桧市不会太久，不过……

你感觉到织莉子的目光落在你身上，而且你*确实*想跟沙耶香聊聊关于双子那一整团……乱麻。现在也许是最好的时机。
