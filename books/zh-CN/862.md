# 危险课程 50

剧透：投票结果

- [x] 你在这里已经做不了更多了。回去找其他人。
- [x] 去找有希和麻美
  - [x] 短期内这件事你想找织莉子商量一下。如果她的能力能看到净化之种里面的东西，把那种效果做成附魔护目镜应该是最快的方法，让爱理能自己判断进展。
    - [x] 也许还有茜？她对现实的视角相当独特。
  - [x] 提一下不通过孵化者的心灵感应
    - [x] 妮可有什么发现了吗？有什么可以实验的思路？
  - [x] 道别然后回家

你走向门口时努力掩饰脸上的苦涩，最后环顾了一眼这间凌乱的房间和爱理瘫在椅子里的身影，然后轻轻把门合上。很难不觉得今天在这里是一次失败，但只有时间才能证明一切。毕竟进展很少会以巨大的飞跃出现，你希望爱理能相信这一点。

你想说点什么，但……你也累了。

不过你还是多留了一会儿，确认她灵魂宝石里的悲叹已经回落到比较正常的速率才真正离开。你能感知到爱理把自己扔回了床上，蜷缩着身子把净化之种抱在怀里。但她的灵魂宝石保持稳定了，那股悲叹的洪流已经减弱。

至少这一点，你要确认。不管她多想让你离开，*这*是你愿意接受的最低限度。

暂时只能这样了。

跟帕罗那次一样的教训：有时候你需要退后一步，看看有没有*别人*能帮上忙。你是爱理被囚禁的象征，是她复仇受阻的化身。虽然你向她承诺了让她的朋友回来，但要跨过这个简单的事实确实不容易，你想……不过你相信她会继续尝试。你必须相信这一点，尽管心里并不踏实。

你任由双脚引导着你的分身沿着有希大楼的走廊走去，脚步无声地踩在地毯上，观察着魔力在墙壁中流动、扭曲着空间的方式，一路走回那间小客厅。

"——福岛郊外有一家很棒的温泉旅馆，我们去过好几次——"忍的声音在你推开门时停了下来。"啊，薇小姐，欢……迎回来？"

她的目光飘向你的本体——还偎在麻美身边。你睁开一只眼看了她一下，然后又紧紧闭上。

"麻美————"你哀嚎着，在房间里扫了一眼，然后把你的悲叹分身晃晃悠悠地挪到沙发前，扑倒在麻美怀里，半跪在她面前的地板上。

"这么糟？"她问道，声音里关心和忍俊不禁在打架，她合拢双臂把你们俩都抱住，轻轻拍着你的头。

你发出一声含糊的、无意义的声音。

"你会想到办法的，萨布丽娜，"麻美温暖地说。"我相信你。"

你听到翅膀扑扇的声响，穆金落在你的悲叹分身肩膀上，用小脑袋蹭着你的头，轻轻叫了一声。

"到底*怎么样*？"有希问。她还坐在麻美对面，侧着身子让忍打理她的头发。你能想象她好奇地看着你，完全无视朋友在摆弄她发型的不雅——显然，法式辫还不够精致，有希那一帘深紫色的头发正在被慢慢编成复杂的多层编发。

"……客观来说，不太好，"你承认道。这个话题大概值得比你脸贴着麻美时含糊不清的嘟囔更多的关注，于是你不情愿地让悲叹分身消散，取回你的灵魂宝石，半滚半翻地靠到她旁边，面对有希。"主观来说……说实话，好坏参半。"

麻美伸手搂住你的腰，轻轻一收。

"能详细说说吗？"有希说。

"她的情绪状态不太好，考虑到她经历的一切，其中很大一部分原因是她……嗯，被关着，"你说，然后放慢语速仔细斟酌措辞。毕竟麻美就在你身边。"而且她看不到自己在我交给她的项目上取得了多少进展，这大概也没什么帮助。"

穆金不满地嘎了一声，然后在你身旁的沙发上安顿下来，你下意识地用空着的手挠了挠他的头后面。

"听起来她是抑郁了，"忍评论道。

"嗯，"有希说着皱了皱眉。"正常情况下这对我们任何人来说都等于死刑，所以我之前没考虑过这个，但……我*确实*注意到她需要更频繁的净化。这倒是*能*解释她为什么没胃口。"

"是啊……"你叹了口气。"她还没到*悲叹螺旋*的程度，但……"你苦笑了一下。"说实话，我不知道该怎么跟她相处，而且我不确定*我*是跟她说话的合适人选。"

麻美换成轻轻抚着你的背，无声地安慰你。

"说来说去又回到我们需要专业心理咨询师的问题上了，"有希摇着头说，被忍牢牢按住脑袋时皱了一下。"我明白了。"

"是啊，"你说。

"听起来她需要更多的社交互动，"忍评论道。"给她开网络连接应该有帮助，不过你的那个虽然挺可爱的，有希，但她可能会想见到另一张脸。我不介意试试。"

"也许吧，"有希表示。"你觉得呢，萨布丽娜小姐？"

"如果你愿意，七海小姐也愿意的话，可能会有帮助？"你说着朝忍点了点头。"我……不过*要小心*。我不知道她现在的精神状态是否适合做什么事，但她的魔法和能力意味着如果她想搞事的话*有*那个潜力。"

有希微微颔首。

"当然，"她说。"我们会小心的，毕竟她现在是我们的责任了。"

你鼓着腮帮子吹了口气。

"嗯，说得也是，"你说。"抱歉把这些都丢给你们了。"

"遇到解决不了的问题是正常的，"有希不以为意地挥挥手。"你加入联盟不就是为了这个吗？有时候你失败了，别人会把你扶起来。"

"说得也是，"你不太开心地说。"谢谢你，鹤屋小姐。"

"我有个问题？"麻美说，仍然轻轻抚着你的背。

"嗯？"你说，勉强对她笑了笑。

"你说她看不到自己的进展？"麻美好奇地问。

"哦，对。我让她用一颗净化之种做一个项目，"你说，又一次仔细斟酌着措辞。"但她，呃，没有像我一样的悲叹感知或者魔法能力。"

"啊，"麻美点了点头。"也许可以教她？"

"嗯，其实我跟她简单讨论过这个，"你说。"可惜的是，考虑到沙耶香对我的魔力的反应，我不觉得我能教或者分享*我*这种形式的魔力感知，但……也许织莉子，或者俊道小姐，或者……我也不知道。肯定有某个魔法少女拥有合适的魔力感知能力，能附魔到护目镜之类的东西上。"

麻美点了点头。

"那确实有道理，"她同意道。"你告诉她你会想办法了吗？"

"……告诉了，但我觉得那时候她已经不想理我了，"你苦着脸说。"我说了，但我觉得她没有*听进去*，你懂吧？"

"我来跟她说，"忍主动请缨。

"谢谢，七海小姐，"你朝她点了点头。

"那听起来有方案了，"有希说。

"哦，说到这个，也说到魔法项目，"你赶紧抓住另一个话题，好把麻美的注意力从爱理那个涉及净化之种的项目的*具体内容*上引开。"我还想起来一件事，我们真的需要搞定不通过孵化者的心灵感应了。少一些窃听，多一些好处。"

有希不太优雅地哼了一声。

"你说的有道理，"她干巴巴地说。"但那可不是什么小工程。"

"哦，当然当然，"你表示同意。"但安全的通讯手段实在太*重要*了。我有好几个方向可以探索，首先当然就是麻美。"

"我？"麻美眨了眨眼。"哦，我的魔法？"

"你的魔法，"你微笑着确认。"*也许*它可以成为一种新型心灵感应的基础？我们得找时间做些实验。"

麻美满脸绽放出笑容。

"我很乐意，"她开心地说。

你对她咧嘴一笑，然后转回去面对有希和忍。

"总之，我现在提起这个是因为我想问你们在路上有没有遇到过魔力可能朝这个方向发展的魔法少女？"你说。

"恐怕我想不到，"有希思考了一会儿说。"如果遇到了我会通知你的。"

"留意一下企鹅主题的魔法少女，"你一脸高深莫测地点了点头。

有希抿了抿嘴唇，给了你一个*明确拒绝接茬*的眼神。你咧嘴一笑，给自己倒了一杯新茶，得意地啜了一口。接下来话题转向了轻松的方面——显然麻美之前在问福岛周边有什么好去处——你们又闲聊了大约二十分钟，然后就到了该走的时候。

有希送你们出来，她的头发现在已经被编成了复杂的多层编发，垂在背后。

"回头见，"她郑重地说。

"如果一切顺利的话今晚就见！焰和仁美那边的公寓有消息了我告诉你，"你开朗地笑着说。"谢谢你招待我们，也谢谢你送我们回去。"

"完全不是问题，"有希说着抬起手，魔力在她的指尖缠绕。

世界猛地一跳，你迈步走回午后的阳光中，仓库君的沙质地面在你的靴底沙沙作响。麻美牵住你的手，手指滑进你的指间轻轻握了一下，穆金振翅飞起，嘎嘎叫着。

"接下来做什么，萨布丽娜？"她微微笑着问。"学校快放学了，我记得杏子和沙耶香放学后安排了一次训练？不过……我不确定还算不算数。"
