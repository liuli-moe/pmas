# 危险课程 30

剧透：投票结果

- [x] 你的预言说你是在我不在城里的时候死的，而我现在就要出发去翌桧市送灵魂宝石
- [x] 到了翌桧市，我们可以看看海香能不能用她的能力从你记不清的预言里找到更多线索。
- [x] 路上我们可以讨论其他线索和调查方向。
- [x] 沙耶香已经申请了年假，所以你们不用一路上尴尬地共处
- [x] 把双子的收藏飞到妮可那里
- [x] 接上有希，飞回见泷原，让她去找栋楼，同时你去订一批酒店房间

"非常感谢，"你对织莉子说，但说着说着，记忆和想法就涌上了脑海。你转过身，皱着眉望向窗外思索。只花了几秒钟，逻辑就排列好了，计划成型。"我……"

"怎么了，萨布丽娜？"织莉子问。

"如果我没记错，你的预言并不是说你会在二十六号那天*被杀*，"你缓缓说，在开口前花时间整理思路。你必须说服织莉子，*而且*还得说服焰和沙耶香。"确切地说，那是你看到自己活着的*最后一天*——在其他情况下，你甚至可能在那之*前*就死了。对吗？"

"我想是的，"织莉子承认。"有……很多不同的场景里我的存在被终结，但很难确定细节，尤其是现在——随着……我能力的改变，我曾经看到的预象也从我手中滑落了。我想这在象征意义和主题上都很贴切，但在这个情况下，未免有些不方便。"

"'不方便'，她说，"你嘟囔着，转过身让她*看到*你在翻白眼。"好吧。我记得你明确告诉过我，只要我在就不会发生。你还记得吗？"

"记得，"织莉子说。

"那好，我们现在距离那个字面意义上的死线还有八天，"你说。"而我正计划着出城。"

织莉子眨了眨眼。

"我……理解你的意思，但……那种事在我的预言里好像从没这么早发生过？"她说，听起来有些不确定。她轻声一笑。"你的关心我很感激，但我觉得这次没必要。"

"哦，"你泄了气，靠在墙上。"那好。我也*确实*……好吧，听着，我有个计划，不止一个理由的那种。计划就是你跟我们一起去翌桧市，路上我们讨论进一步的应对方案和调查方向。"

织莉子好奇地看了你一眼，同时在纪里香温柔的催促下靠到桌边。

"我*确实*有些事想跟你谈，路上说就行。"一根手指竖起，然后第二根。"第二，我想看看海香能不能用她的能力从你记不清的预言里找出更多线索——她的魔法*很奇特*，我怀疑可能管用。"第三根手指。"沙耶香已经申请了年假，所以*那方面*的尴尬没了。最后但绝对不是最不重要的，你们俩该出去透透气了。"

"我们昨天去了购物约会！"纪里香开朗地说。"超浪漫的！"

"那只是买了些日用品，纪里香，"织莉子对她温柔地笑着。"还有一些衣服。"

"跟*你*一起的就是浪漫的，"纪里香坚定地点头，空着的手梳过织莉子的头发。

"哦，不错！是啊，购物就是购物，但你知道我的意思，"你说。你现在想起来了——爱荷华事件之后她们获得了外出许可。"所以嘛。你自己决定，织莉子。即使现在没有什么迫切的需要来……我不知道，*保护*你，但我觉得看看海香能不能搞清楚什么总是好的？在我看来，信息才是关键。"

"出去一趟倒也不是不行，"织莉子让步了。"不过我建议你先跟晓美和美树确认一下。"

"嗯，我本来就打算的，"你说。"但我想先听你的意见，毕竟如果你不想去，那整件事都没意义了。"

织莉子轻笑。

"你有了，"她说。"而且……谢谢你，萨布丽娜。"

"那当然了，"你说。"你们现在是我的朋友了嘛。"

"对！"纪里香比织莉子端庄的点头慢了半拍。

"太好了，"你说。"我去跟焰和沙耶香确认一下。"

"我想我们该在走之前先洗碗，"织莉子说，带着微笑从桌边推开身子。"谢谢你。"

"不行，*不要*谢我，"纪里香嘟着嘴说。"不洗碗。"

你偷笑着冲她们挥挥手，若有所思地看着织莉子离开时——你敢说——脚步都轻快了起来。你把注意力拉回窗外，盯着雨出神。雨似乎终于要停了，最后那阵倾盆大雨是暴风云最后的挣扎，持续的雨幕开始消散，见泷原市中心的摩天大楼终于清晰可见。飞去福岛的路上应该能晒到太阳了。

但在那之前，你还有事要处理。

"*嗨，焰，沙耶香？能聊一下吗？*"你再次伸出心灵感应。"*没什么事，就是有个事想快速商量一下。*"

"*什么事，萨布丽娜？*"尽管你已经先打了预防针，焰的回应几乎是瞬间的，语调平淡但并非无情，边缘处隐约有一丝关切。

"*我带织莉子和纪里香去翌桧市行不行？*"你问，目光再次扫过见泷原的天际线。你其实从这里看不到见泷原中学——角度完全不对——但你能想象她们现在的样子，焰姿势笔直、看似全神贯注地上课。沙耶香，也许，一脸走神的样子，因为你又往她腿上扔了个大问题。"*全程在我视线范围内，我想让御崎小姐检查一下织莉子。*"

"*……为什么？*"沙耶香问。她听起来没有*生气*，只是有些困惑，倒让你松了口气。焰的沉默里有一种谨慎好奇的质地，你就当她是在附议这个问题。

"*在她……幡然悔悟之后，她的能力也*跟着变了，*"你说。"*同时也模糊了她当时实际预见的那些东西的记忆。我想看看御崎小姐能不能挖出那些记忆。特别是，她预言自己大约一周后会死于某种她无法确切定义的东西，而我*真的*很想了解更多。*"

"*要是她撒谎呢？*"沙耶香阴沉地补了一句。"*骗你同情之类的。*"

"*更需要找第三方来确认了，*"焰低声说。"*是个好主意。*"

"*确实，*"你谨慎地说。你忍不住想在这里坦诚。"*这不是我最初的想法，不过确实是个好处。老实说，我不觉得她在骗人——*她*才是今天主动提起的那个人，而且编一个注定会被揭穿的谎对她没有任何好处。*"

"*或许吧，*"沙耶香不情愿地说。"*嗯，听起来是个好计划。拿到确认和她掌握的那些关于什么神秘威胁的信息。*"

"*同意，*"焰低声说。"*谢谢你告诉我。告诉我们。*"

"*当然了，*"你说，温柔地微笑。"*我答应过的。*"

"*……嗯，你答应过，*"焰说。"*谢谢。*"

"*好了，那……再见了，*"你说。"*结果出来告诉你们。*"

"*再见，*"焰低声说。

你微笑着结束了这通心灵通话，沙耶香也跟着说了句带笑的道别，你感觉心情轻松了不少。你忍不住觉得焰的心情最近在好转。一部分是因为事情在朝好的方向发展——这*多少*有你的功劳——但也因为她愿意给你那么一点信任，尽管她被辜负过那么多次。

那一点点希望就是*一切*。

你脚步轻快地下了楼，笑容几乎咧到耳朵两边，走进已经空了不少的客厅回应着大家的问候——沙耶香那声快活的"嗨"*尤其*带着笑意——然后一屁股坐回麻美旁边给她一个拥抱。

"*你*心情不错嘛，"她亲切地说。

"对啊！"你说，环顾四周。织莉子和纪里香不见了，但你听到走廊深处传来流水声、瓷器碰撞声和偶尔的咯咯笑声，所以不用费脑子就知道她们去了哪里。纪子和明美还蜷缩在沙发一角，头低着对着双子的灵魂宝石说话，不过纪子路过时冲你点了点头。然后是杏子和由麻，还在沙发一角蜷着，杏子瞪着天花板看，沙耶香——

"沙耶香决定专心上课了，"麻美说着拿出一串缀着五彩小宝石的钥匙扣。"她说反正午饭时就见了。还说她在休假？"

"啊，是的，"你说。"嗯。我是说，我们也不需要所有人随时待命嘛，所以……带薪年假！"

"嗯……你也该度个假，"麻美说，语气里带着淡淡的笑意，又把宝石递给你。

"那*确实*不错，"你若有所思。你把麻美的手指合拢在宝石上，给了她一个快速的微笑——她和你一样是沙耶香的朋友，完全没理由不让她帮沙耶香保管。"可惜今天不行。渡边小姐、齐藤小姐？一切顺利吗？"

"啊，是的，我们在尝试多跟双子聊聊，毕竟以后要住在一起了，"纪子抬起头。"进展……还行。"

"*我们不懂渡边小姐（太多身体了！）！*"双子插了进来——大概是注意到你在关注她们。那种黏腻谄媚的崇拜仍然从语气里滴落，但掺杂着困惑。"*但我们的天使把我们托付给了她们（她一定知道些我们不知道的！），所以我们在尝试理解她。她的灵魂宝石也很闪亮（但没有你的闪！），肯定有什么原因！*"

"*是的，理解她会有帮助的，*"你小心地说。"*但我不是完全把你们扔给她们，我会来看你们的，好吗？*"

"*好的！我们明白了！*"双子说。"*我们会努力的！*"

"*这就够了，*"你严肃地说，然后结束了心灵感应，试图甩掉她们对你那种纯粹宗教*狂热*般的崇拜带来的不适感。你短暂地想过问问"天使"这回事——天使意味着更高的力量，这完全符合你对自己来历的推测，但……算了。麻美的手碰了碰你的手，让你心安下来。

"好了！"你说，果断抛开那条思路，冲麻美感激一笑。"那，呃，杏子——"

"我们走，"她闷声说，暗淡的深红色眼睛迎上你的目光，带着挑衅。

"……好，我又没打算劝你不去。只是想确认还有没有别的——没有？行。"你不确定杏子*为什么*想去，特别是沙耶香不去的情况下，但她钉在你身上的那道目光说明她确定，而你没有理由拒绝。"那我们就等美国姐妹了，然后就可以出发了？"

"不用再等了，"织莉子的声音传来，比她本人走进客厅早了几秒，她正用一条小毛巾擦手，纪里香蹦蹦跳跳跟在后面，手可疑地干燥，裤子可疑地潮湿。"抱歉耽搁了。"

"没事，正好，"你说，微笑着。"我刚好忙完，焰和沙耶香也同意了。"

"公路旅行！"纪里香欢呼。

"公路旅行，"你严肃地附和。"你们准备好了吗？"

织莉子犹豫了一下，低头看了看自己身上那件素淡的绿色连衣裙，片刻后纪里香的手找到了她的。织莉子吐了口气，对纪里香淡淡一笑，然后坚定地对你点头。

"准备好了，"她说。

"那出发吧！"你说。"渡边小姐、齐藤小姐，要不要我送你们回去？"

明美抬头看你，微笑着。

"谢谢，不用了，"她说。"我们走路回去——多跟人接触总是好的。而且雨也停了对吧？"

"啊？那也是，"你说，点点头。"路上小心，有事随时打电话。"

"好的，"她说，起身站了起来。

没过多久，你们全都走到了外面，耐心等着织莉子锁门——纪子和明美已经先走了，一人带着一颗双子的灵魂宝石。然后，就向福岛出发了，乘着悲叹打造的飞行器冲入放晴的天空，阳光洒在背上，清冽的凉意还有残余，世界在暴风雨过后仿佛闪闪发光。空气中弥漫着一种清澈空灵的气息，你们乘着悲叹之器升至城市上空，珍贵的灵魂宝石木箱安放在专门为它打造的凹槽里。

"彩虹！"纪里香开心地喊着，从她幸福地窝在织莉子腿上的位置指向前方。

"是的，亲爱的，"织莉子说，双臂环着她的腰。"我觉得谁都不会看不见的。"

果然，一道绚烂的弧线——几乎是一个圆——悬在前方，虹彩转瞬即逝却*真实*地铺展开来，浓墨重彩地绘在放晴的天空和散去的云层上。你和麻美相视而笑，她依偎在你身侧，一脸满足。今天本是上学日，她逃了课，因为出了事你打了电话，她没有犹豫，*永远*不会犹豫赶到你身边。

唉，算了。

你把那些忧虑放到一边，尽情享受眼前的景色——日本在你脚下展开，大片大片的田野、森林、道路、河流和建筑，绿色、棕色、蓝色交织，远处隆起的丘陵和山脉构成日本的脊梁。

就连杏子也似乎没法对这景色保持阴沉了，后排座位上那团不满的雷云随着你们飞越大地而消散，由麻开心的笑声响起，她探出窗外，享受着风的冲击。

可惜太快了，你们就在向福岛市下降，绕过信夫山朝有希的大楼飞去。那栋旧办公楼跟你上次看到时一模一样：从外面看，废弃、破败、*毫不起眼*。对感知不到魔力的人来说确实如此。完美的伪装，让官方和非官方的目光都从这座堡垒——和*家园*——上滑过，这是有希为自己和朋友们打造的地方。

……你忍不住想起她之前说的，她的能力在可以成为*家*的建筑里效果最好。说到这个，你又想起了她的心态——彻头彻尾的务实至上——以及她那么在乎那座神社。

你把这些想法搁到一边，因为说到有希，你看到她娇小的身影站在屋顶上，裹在那件翠绿色斗篷里，头微仰着仿佛被那个严整的发髻压住了似的，追踪着你们的降落。

"早上好，"她微微颔首说道，目光扫过你的朋友们，一一打量。

"早上好！"你说。"你怎么样？"

"很好，谢谢，"有希带着淡淡的微笑说。"对了，薇小姐，我想提醒你，帕罗小姐希望跟你谈谈——之前开会的时候我们俩都忘了这事，不过你从翌桧市回来的时候安排一下也许比较好？"

"……可能吧，"你说，皱着眉。你确实忘了这事。如果被俘获的爱荷华组首领想跟你谈谈，你大概*应该*跟她谈，但……你午饭得赶回家。你得跟妮可聊身体的事，跟织莉子和海香聊预言的事，还可能得跟帕罗聊……她想跟你聊的事。

你看了看手机上的时间。

差不多十点，还有两个半小时。
