# 危险课程 31

剧透：投票结果

  - [x] 我带了试验对象来！织莉子这里有关于她死亡预象的记忆，海香有记忆方面的能力？然后我们得给这些女孩重建身体。妮可，你需要悲叹方面的帮助吗？
  - [x] 帕罗
  - [x] 好，你会跟她谈……
  - [x] 不，现在不行。午饭时我们要做一个东京行动事后总结，还有一些关于星座联盟的事要讨论。
  - [x] 接上有希，飞回见泷原，让她去找栋楼，同时你去订一批酒店房间

你盯着手机皱了几秒眉，脑子里的日程安排像拼图碎片一样挪来挪去。当然你想跟帕罗谈，哪怕只是满足你自己的好奇心。但问题是*时间*——如果你现在跟她聊，就会挤占你跟妮可和织莉子搞清楚事情的时间。

……严格来说你不需要亲自在场。你看了看麻美、织莉子和纪里香——你的朋友们完全能照顾好自己，妮可和海香也都是各自领域的行家。所以你*可以*先让她们去，然后你跟帕罗谈完再赶过去，最后赶得上午饭。这样安排挺好的。

你嘴边已经有了个同意的答案，但又及时收住了。老实说，反过来做更方便。先跟大家一起去翌桧市，反正之后你本来就要安排有希去见泷原占一栋楼——然后通过鹤屋传送特快专递™快速回到福岛跟帕罗聊。

……而且你跟焰和沙耶香说过你会亲自看着织莉子和纪里香。当然了，麻美也完全能胜任，但……你说了*你自己*会看着。你有些惭愧这个想法竟然排在了最后。

"我会跟她谈的，"你慢慢说，试图把那个想法搁到一边。"不过不是现在——之后能不能借你走一趟捷径，鹤屋小姐？当然是在你建好到见泷原的连接之后。"

"当然，"有希回应道，淡淡一笑。"说起来，不在敌对组织的首领一开口就跳起来响应，大概也是明智之举。"

"……可能吧，"你勉强承认。你对*这种*思路不太自在，但她说得大概有几分道理。"还是不知道她到底想干什么？"

"遗憾的是，她完全不愿意多说什么，"有希说。她看起来颇为恼火，双臂交叉抱在斗篷下。"如果让我*猜*，她想试探你的分量，看看有没有可能尝试逃跑。她当然也试过摸我的底。"

杏子轻轻哼了一声。

"我想这也不算太意外，"你说，瞥了杏子一眼——被她无视了。"那好，这事之后再说。现在先去翌桧市？"

"当然，"有希点头。"现在传送，各位请稳住。还有，呃，请不要介意翌桧市那边接应的人可能有些……过于热情。我会搞定的。"

……什么意思？但你没时间追问，因为有希只给了你片刻消化的时间，嘴角浮起一丝坏笑，然后现实就——

——*撕裂*了。

你猛然身处别处，太阳跳到了右边，晴朗的蓝天换成了灰蒙蒙的流云。信夫山不见了，天际线换了一个，城市的低鸣声也*不同了*——那种差别你永远说不出来，但确确实实存在。就连脚下脏兮兮的水泥屋顶感觉都不一样，虽然那可能是你的想象。

"嗯，你能——"你转向有希，却被迫后退一步——一道魔力闪现，一只*巨大无比的爪子*越过你伸来，娇小的女孩灵巧地侧身避开。

悲叹应声而至，刀刃在空中凝结——就在你认出那只爪子的前一瞬——锋利的爪子、毛茸茸的棕色毛皮、侧面粗糙的缝线——顺着它往上看到沉重倾斜的肩膀和一双燃烧般的黄色眼睛，一只巨型泰迪熊俯视着你们所有人。你身边，麻美稍微放松了些，火枪枪口朝下指着屋顶；身后，你*感觉到*而非看到纪里香正举着反魔法和爪子待命。杏子和由麻也没有放下武器。

"这次不行哦，若叶小姐，"有希说，安全地站在泰迪熊够不着的地方。

"总有一天我会抓到你的！我说了，叫我未来嘛。"一扇屋顶舱盖砰地打开，一头薰衣草色的蓬松毛发探了出来。"哦，嘿！是和美的前辈和她女朋友！还有朋友们！"

"我和若叶小姐之间有一场持续的较量，"有希和气地解释。"她试图用她的熊哨兵抓住我，我躲开她。目前比分是三比零。"

"这是*拥抱*不是*抓捕*好吗，你那么小那么可爱我就想给你一个*拥抱*。你不是让*和美*抱了嘛，"未来从屋顶上爬出来，梯子在脚下咣咣响，一脸不满。"大家好。有没有吓到你们？"

你和麻美交换了一个眼神，她收起火枪，你把悲叹遣回锤子空间。她耸耸肩，掩住一丝笑意，目光往下瞥了一眼，又朝见泷原的方向扫了扫，然后看向你——你忍不住回以一个歪嘴笑。和美是挺奇怪的，她的女朋友们也是。但话说回来，*你*也挺奇怪的，你有什么资格评判？

……你也不得不承认，有时候你也得压下想给有希来个熊抱的冲动。她*确实*又小又可爱。

麻美忍住了咯咯笑，挽起你的胳膊。

"早上好，若叶小姐，"麻美说，微微侧身示意织莉子和纪里香——后者这时才收起爪子。"给你介绍一下美国织莉子和吴纪里香？她们是我们在见泷原的朋友。还有别忘了佐仓杏子和千岁由麻。各位，这位是若叶未来。"

"很高兴认识你们！"未来说。

杏子只是点了点头，深红色的眼睛远远地望着翌桧市在阳光下闪耀的天际线。

"幸会，"织莉子微微鞠躬。"我们想跟海香聊聊？萨布丽娜觉得她也许能帮我解决一个……困扰。"

"哦，来得正好，咲和海香刚买完菜回来，"未来说。"萨布丽娜小姐，和美说你是来找妮可的对吧？"

"嗯，"你说，把两箱灵魂宝石飘向自己。"她有空吗？"

"她兴奋得不行才是真的，"未来说，宠溺地翻了个白眼。"我马上带你下去地下室……啊，佐仓小姐，你有什么事吗？"

"如果方便的话，我想跟和纱小姐谈谈，"杏子说。你忍不住对她的语气愣了一下——完完全全的礼貌正式，尽管嘴里还叼着根棒棒糖。你*不应该*那么惊讶的，毕竟她是牧师的女儿嘛，肯定学过怎么跟人好好说话。但看到她真的这样说话还是蛮……震撼的。

"啊？其实和美应该已经到了才对，"未来说。"大概是被薰绊住了。总之大家都下来吧。妮可在地下室实验室等你呢，萨布丽娜小姐。"

她带头回到梯子那里，你们一个接一个跟着下去，有人爬有人直接跳，发现自己身处未来博物馆的工作人员走廊——干净明亮，但朴素、实用，没什么装饰。

"对了，鹤屋小姐，我挺意外你能直接在屋顶之间传送我们的，"你提到。

"我也是，说实话，"有希说。"通常我需要所有人都在建筑*内部*才能产生足够的共鸣，不过我跟若叶小——"

"未来！"

"——若叶小姐的魔法之间似乎有一种特殊的互动，"有希无视了打断继续说。"据我了解，她许愿得到了这座博物馆，这似乎对我的魔法产生了某种微妙的干扰？我们也不太确定。"

"……嗯，"你说，摸了摸下巴。"我想不出*怎么*会这样，但我能看出其中的关联。"

"能有更多数据来研究这件事当然好了，"有希说。"但许愿得到*建筑*的情况很少见，原因也可想而知。"

"我看看能帮上什么忙，"你笑着说。"不过在*这*方面不敢保证什么。"

有希轻声一笑，和气地点头，你们跟着未来穿过博物馆蜿蜒的隐秘通道。你隐约好奇这到底是怎么运作的——博物馆大概是对公众开放的。这些是双重隐秘的通道吗？隐藏在工作人员走廊之后，用作未来、和美和其他团员的居住空间？

几乎像是被你的念头召唤出来一样，和美从一扇侧门冒了出来，蹦蹦跳跳地加入你们。

"嘿嘿！"她欢快地叫。"麻美，萨布丽娜！抱歉来晚了，刚在忙。新面孔！嗨！我是和美。"

你做了一轮介绍，告诉她来晚一点完全没问题。杏子的目光在和美身上停留了一会儿，但她没有立刻提出要求，只是拖在队伍后面跟着由麻一起，一行人沿着楼梯往下走。

"好了——妮可在楼下，左边第一扇门，不会走错的，"未来在楼梯间停下。"美国小姐、吴小姐，你们想见海香对吧？我带你们过去。和美，佐仓小姐想跟你聊聊。"

"如果不打扰的话，"杏子客气地说。

这下连*麻美*都一脸困惑地看着她了——杏子照样无视。

这……大概不关你的事，也完全不是你该管的，但你还是忍不住在楼梯间犹豫了一下，一只手搭在扶手上。你当然要把灵魂宝石的箱子交给妮可，不过也许你也想跟织莉子一起去找海香？你在那里悬了一会儿，思考着。
