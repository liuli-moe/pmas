# 危险课程 34

剧透：投票结果

- [x] 我不知道
- [x] 推测：
- [x] 萨布丽娜在她通过超知识所知道的主时间线中并不存在。
  - [x] 顺便说一句，如果那就是命运，那命运去死吧。
- [x] 也许萨布丽娜能改变事情，但羽翼会在萨布丽娜不注意的时候粗暴地把事情拉回正轨。
- [x] 织莉子说萨布丽娜和焰联手能改变命运。也许焰的参与能"锁定"改变。
  - [x] 萨布丽娜和焰在织莉子问题上没有达成一致。如果这是真的，修复这个分歧就是拯救织莉子的关键。
- [x] 织莉子的问题：
- [x] 你能确认或否认这个推测吗？
  - [x] 如果不能，你当时说那句话是什么意思？
- [x] 在你的第一个回答中："她"是谁？遗失的碎片是什么？"她"为什么在找它？在哪里？
- [x] 萨布丽娜的问题
- [x] 不要隐瞒关于萨布丽娜的答案
- [x] 解释Madokami的升天和叛逆
- [x] 不要透露焰或小圆的身份
- [x] 不要提到循环或小圆潜力为何如此巨大
- [x] 避免巫妖炸弹。循环之理的愿望是在魔女诞生前消灭她们。不要进一步阐述。
- [x] 对你自己，逐一排查……
- [x] 织莉子想问的所有问题。
- [x] 你自己关于以下方面的问题……
  - [x] 你在巷子里醒来之前的状态
  - [x] 你的衣服从哪来的（巷子里那时）
  - [x] 你恍惚时做了什么，如果有重大意义的话
  - [x] 你记得焰的羽毛应该长什么样
  - [x] 为什么你的潜力很奇怪
  - [x] 你一直听到的声音属于谁
  - [x] "谁在做梦？"
  - [x] 遗失的碎片在哪里？

你倒吸了一口气。这个问题回答起来可真*棘手*，不是吗？你觉得自己大概知道那是什么，但你必须小心自己透露的内容，因为其中很多并不*属于*你来揭露。但话说回来，你的朋友和盟友有权知道，而且……也许*现在*正是时候。

"我……不知道，"你说，随后补充道，"不完全确定。"

"不完全确定？"有希尖锐地反问。

"我有一些*推测*，"你说。"而且……"你叹了口气。"这么说吧。我的推测是基于我自己掌握的关于某个*可能*未来的知识。就当它是一次性的、非常有限的预知事件好了？"

有希扬起一侧眉毛，放下茶杯，全副注意力集中在你身上。不只是她，海香脸上的轻松也消退了，蓝色的眼睛在镜片后锐利地聚焦在你身上。

"我掌握了一个潜在未来的知识，"你缓缓说。你已经把这些秘密藏了太久——也许你没法揭露全部真相，但……它在此时此刻是*相关的*。"不是说一定会发生什么的，但嗯……如果*那*就是命运，那*去他的*命运。"

"啊。魔女之夜？"有希说，表情极度专注。你几乎能看到她眼后的齿轮疯狂运转，以凶猛的能量推演各种含义。

"……我*本来*还在想你是怎么知道那个的，"海香说。"我其实试着用能力去探过，但什么都没找到。"

"那是其中一部分，"你说。"但我……好吧，所以。我……"

你用手搓了搓脸，短暂地闭上了眼睛。你已经守着这个秘密*太久了*。当然，你信任你的朋友。但*你守着这个秘密真的太久了*，即使把这些秘密瞒着朋友们让你*煎熬*不已。他们有权知道，但你就是……害怕。

害怕事情出错。

害怕朋友们被吓跑。

害怕丘比发现。

一只温柔的手握住了你，将你拉回现实，温暖的手指在你的手背上描画，然后滑到手腕。你微微一颤，靠向麻美的存在，同时挤出一个微笑给她。

"慢慢来，萨布丽娜，"麻美轻声说。"我相信在座没有人会坚持要你马上全部说出来吧？"

"当然不会，"有希说。她的目光依然专注，但刻意向后靠了靠。"就像巴小姐说的——请慢慢来。"

"对，嗯，"你说，颤抖着吸了一口气，又一口。"首先。有些东西我*会*一笔带过。可以随时问我要更多细节，我会尽我所能说清楚，但……很多事本就不是我的故事。它跟其他人的故事和秘密交织在一起，你们懂的吧？"

你忍不住遗憾沙耶香不在场，必须说一句。毕竟她也有权知道这些。

"当然，"有希点头。

"所以，"你说，咬着下唇内侧。"沙耶香被……推进去的那个魔女？在我所知道的未来里，是跟沙耶香有密切关联的。这一点我可以确定。而且在那个……呃，羽翼介入之前，沙耶香根本不会靠近那个魔女。所以我*推测*羽翼是在试图进行某种……轨道修正？"

有希打了个寒颤。

"希望你别介意我这么说，但这话*太吓人了*，薇小姐，"她说。

"……嗯，也许稍微让人安心一点的是，我*能*改变那个未来，而且我一直在努力*做到这一点*，确保我所有的朋友都是*安全的*，"你平静地迎视她的目光。"我……抱歉以这种方式提起来，但就是……唉。我希望你能理解*为什么*我在这件事上一直想要谨慎。这不是打开一个蠕虫罐头的问题，更像是铁罐子里装着尘世巨蟒。"

"我完全理解，"有希微微颔首——但她的皱眉丝毫未减，双臂交叉在斗篷深处。"但我也希望你理解*我的*顾虑。"

"是，"你说着龇了龇牙，搓了搓脸。"……抱歉。"

"说清楚，我没有任何打破联盟的意思，"有希将全部的凌厉目光投向你。"我说话算话，而且我始终相信做你的盟友是值得的，特别是从长远来看。但我希望你尊重一个事实——你确实是在要求我们所有人付出很多。而且我认为说我们想了解这个……问题的全貌以便更好地理解我们面对的是什么，这一点都不过分。"

你呼出一口气，压下那股内疚的火焰。从某种意义上说，被这样斥责几乎是一种*解脱*。你一直在保守秘密，当然人们不会对此高兴。你不是说你乐于被训斥，但这种反驳有种恰如其分的正当性。你不是唯一在这件事上有利害关系的人，不是唯一引导你们集体航向的人。

"……说得再公平不过了，"你承认，握紧麻美的手，从这份触碰中汲取力量。"好吧。那么。接下来这个……我之所以有信心我们不是特别走投无路，是因为在我所知道的那个未来里*没有我*，尽管那是我*会*出手干预的事情，你懂的吧？"

麻美的手紧了一瞬，你能感觉到那股紧张骤然贯穿她的身体，然后她刻意放松下来，更紧地倚靠在你身侧。

"所以你相信你的行动是……某种对那个未来的干扰因素？"有希说着抿了抿嘴。"而且……啊，我明白了。那就是你对改变所预见的未来抱有信心的根源。你验证过吗？就是说，你确实遇到过你预见过的事件，并且通过你的行动导致了不同的结果？"

"是的，确实如此，"你坚定地说。"坦白说，那样的例子太多了根本列不完，影响也层层扩散开来，事情已经*大不相同*了。"你轻声笑了笑。"我们现在能坐在这里聊这些就是证明。"

"而且我能从另一个角度来证实，"织莉子说。"萨布丽娜已经无数次超越了我的预知。"

沉默蔓延开来，浓稠而黏腻，充满纷忙的思绪——有希若有所思，海香则看起来几乎……兴奋。沉思着，但兴奋着。织莉子的目光扫过来，海泡绿的眼睛与你的对视一瞬，然后她微微一笑，重新端起桌上的茶杯，趁机蜷到纪里香身边。

你……有个问题就在嘴边。织莉子曾说过你*和焰*能改变命运，你想确认这一点。也许正是因为你们两个没有在某个议题上*同时*站在同一边，羽翼才有了可乘之机。

焰已经对沙耶香改观了。不完全是，但多亏你给了焰机会从*不同的角度*看到沙耶香，焰对沙耶香的评价已经明显提高了。而且你*知道*焰明白沙耶香的死会把小圆也拖下去。

而且羽翼在那第一次之后再也没有出手针对过沙耶香。当然，*是你*在结界实验的那次事件中不知怎么地打开了让它影响现实世界的大门——而你从那以后一直坚决不给它第二次机会。也许只是羽翼没再有那个机会。但你忍不住在想。

焰*没有*改变她对织莉子的看法……

……而织莉子预言了自己的死亡。

所以问题是：仅仅是因为你和焰在这个议题上没有达成一致吗？

但是。

这个问题你不愿在这里大声说出来。不是在这里。你信任有希，也愿意把这份信任延伸到她团队的其他人。你信任海香，也信任和美以及昴宿圣团的其他人。*但是*。

你并不了解她们。

你不介意把关注焦点放在自己身上。你本就是一个跟魔法、跟*命运*有着*奇特*互动的人。如果她们还没有把二加二拼起来，特别是考虑到俊道茜那整件怪事，那么*这次*对话，此时此地，只会更加凸显这一点。你许了一个怪异的愿望，得到了怪异的力量，你的本质就是*怪异的*，无视因果、命运和时间。你愿意承认这些。

你*不*希望焰承受那种关注。

*焰*不想承受那种关注。而*她的*秘密你毫无保留地会守住。

所以你暂且按下了这个念头。

"那我有个问题，织莉子，"你开口，打破了持续的沉默。"你得到的第一个答案——你能感觉到什么额外的细节吗？'她'是谁，遗失的碎片是什——"

织莉子已经在摇头了。

"我不知道。御崎小姐的魔法没有恢复我的记忆，只是给我提供了提示，"她说着犹豫了一下，放下茶杯。"但我会试着问一下。"

你点点头。当织莉子再次将羽翼笔落在纸上时，有希动了动。

"薇小姐，听起来你所看到的未来比美国小姐的预知要……更加确定，"她注视着你说。"也就是说，美国小姐有的是随情势变化的闪烁片段，而你掌握的是一条确定的轨迹。是这样吗？"

"没错，是这样，"你说。"我……我猜你想知道更多？"

"猜对了，"有希说。

"嗯……我会尽量说得笼统一些。因为再说一遍，很多东西不该由我来说，"你平静地迎视有希的目光。因为在*这件*事上你*绝不*会动摇。"而且我*必须*强调——拜托，*拜托*小心在什么时候什么地方分享这些信息。如果信息落入错误的人手中，后果不是可能，而是*一定*会是灾难性的，我想你们会明白为什么。"

有希示意你继续，她的表情专注而不露声色。海香也点头，那种奇特的兴奋与审慎混合在她的表情和姿态中。

感觉像是站在悬崖边上。这是你第一次与*任何人*分享这些秘密。

"嗯。核心是这样的：在未来的某个时间点，有人会——呃。有人……会许一个愿望？"你皱了皱眉。"时态太难了。那个愿望是消灭所有的魔女，在她们诞生之前。那个愿望催生了所谓的循环之理。而那个愿望的量级……那个女孩*变成了*一个超越时间的存在，成为了律法本身。因为她许愿要用自己的双手消灭*所有*魔女，过去、现在和未来。"

在场几乎所有人都倒吸了一口凉气。

"但魔女*确实*存在啊！"纪里香指出，语气明快而欢脱。

"我注意到了，"你干巴巴地说。"但这是……你看，这是对一个未来的预见，我……*本以为*还没有发生？*因为*魔女仍然存在？"

"或者……'律法已碎'，"织莉子轻声引述。"所以魔女再次存在了。"

"所以我们面对的是某种东西*违抗*了一个*极其*强大的愿望所产生的后果，"有希说。"而在我的经验里，能直接对抗一个愿望的东西屈指可数。"

她叹了口气，手掌拖过脸庞，那张平静的面具终于落下，露出严峻的沉思，随后站起身来，斗篷披垂在身上。

"失陪一下，"她说。"我需要一点时间想想。御崎小姐，你不介意吧？我不会走远，大概就到走廊尽头。"她的目光扫向你。"请放心，我坚持我说过的话，薇小姐，而且我绝对不会向任何人透露这些。尤其不会通过心灵感应。"

"请便，"海香说。"就是注意那些标了绿色的门，那些通向我们私人空间之外。"

有希点头，朝门口走去。
