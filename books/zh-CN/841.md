# 危险课程 29

剧透：投票结果

- [x] 跟沙耶香谈谈
- [x] 巫妖的事刚被甩到她脸上了，我们见过另一个版本的她因为这事自我毁灭。
- [x] 她这次是睁着眼睛进来的，但我们想确认她真的没事。
- [x] 别碎碎念也别自作主张。倾听她的感受。
- [x] 织莉子有话想跟你说
- [x] 把双子送到盐竈组那里
- [x] 把受害者的收藏飞到妮可那里
  - [x] 顺路接上有希，飞回见泷原，让她去找栋楼，同时你去订一批酒店房间

没错，*现在*就是最好的时机。你可以说想再给沙耶香一点缓冲时间，但她已经有不少时间了，而且……她*看起来*还好，靠在沙发上揉着由麻的头发。杏子扫了你一眼，表情看不出什么来。

*而且*你也想在去接有希之前跟织莉子聊聊。她开了口，你不想把事情拖到发酵，尤其是你怀疑自己大概知道是关于什么的。

"好了，"你说，把茶杯放下，发出清脆的一声响。手一挥，浮在空中的肖像消散——通话已经结束了。"好，那！呃。首先，我要把双子交给你们，渡边小姐、齐藤小姐？"你等她们点头才继续。"然后……沙耶香，能跟我单独聊两句吗？然后是织莉子。之后我和麻美出发去翌桧市……话说沙耶香，你要不要一起来？随你。"

"呃……"沙耶香挠了挠头。"让我想想。"

"我去，"杏子闷声说。

"你——啥？去翌桧市？"你对杏子眨了眨眼。

"嗯，"杏子说，表情让人看不透。"由麻也去，当然。"

"呃。"你和麻美交换了一个眼神，她也耸了耸肩。"行吧？我可以带你们，没问题。"

杏子点点头，靠回沙发，但没忘了从咖啡桌上再拿一小叠饼干跟由麻分享。现在你有点困惑，因为"看不透"这个词简直精准到不行——你实在想不出翌桧市有什么是杏子会感兴趣的。

"……好吧，呃……行。我先跟双子说一声，告诉她们接下来的安排，"你说，一边用心灵感应一边伸出手去够那两颗灵魂宝石，仍然被你的悲叹轻轻托着。"*双子小姐，双子小姐？*"

"*在的！（我们的天使！）*"她们立刻激动地回应，心灵声音里满是热切与崇拜。"*你的对话太美了！*"

一股不祥的感觉在你胃里翻涌。

"*等等，你们在偷听？*"你语气陡然严厉起来。

"*没有！我们不会的！（不不不不！请不要生气！）*"她们辩解道。"*只是……（我们能*看到*！）*"

她们能*看到*？

"*……等等。你是说你们能看到心灵感应？*"你问。"*从外面看？*"

"*能！（你不生气了？）*"她们说。

嗯。想想也合理，毕竟她们拥有某种对灵魂和魔法的感知能力。很可能还不止一种。能看到心灵感应也不算太大的飞跃，然后你隐约好奇她们是不是*也*能帮你研究非孵化者心灵感应。当然，这方面你其实不缺方案——麻美的连接魔法、妮可整体的疯狂科学气质，嘿，甚至纪子本人都可能是个选择。

"*我没生气，只是有点意外，*"你慢慢说，放松了下来。"*这不是常见的能力。*"

"*哦，（哦。）*"她们说。

"*总之，*"你说，然后把纪子和明美也拉进了心灵感应对话。"*双子小姐，双子小姐，这位是渡边纪子和齐藤明美。她们是我的朋友。渡边小姐、齐藤小姐，这是双子绫濑和卢卡。*"

纪子和明美都坐直了身子，注意力集中在双子的灵魂宝石上。第一印象很重要。

"*很高兴认识你们（呃……）！*"双子说。

"*幸会，双子小姐，双子小姐，*"明美说。

"*很遗憾我非常忙，没法一直带着你们，*"你说。"*不过渡边小姐和齐藤小姐自愿照顾你们——你们能接受吗？*"

"*嗯……*"

你歪了歪头，打量着那两颗灵魂宝石。你本来预期要么同意——出于对你所谓天使身份的尊重，要么立刻反对——因为要跟你分开之类的。这种犹豫倒是出乎你的意——

等等。

"*……那个多出来的身体是渡边小姐的，跟你们完全没关系吧？*"你试探着说。

"*……既然你都这么说了（天使这么说的话），*"双子半信半疑地说。"*啊，我们不是要质疑你的判断！只是……**那*太恶心了（丑陋的、肮脏的身体）*，她们就不能至少去掉一个吗？*"

"*这不是由你们来决定的，*"你说，克制着保持语气平稳温和。"*而且记住，有我在，她们灵魂宝石被玷污的问题不是问题。*"

"*哦。对！对不起（我们不该质疑天使的）！*"双子说，然后把注意力转向纪子和明美。"*那就拜托你们了，渡边小姐、明美小姐。*"

明美坚定地点点头。

"*我们会尽力的，*"她说，一半是对双子说的，一半是对你说的，同时伸手去接灵魂宝石。你把它们轻轻送过去，明美一手一颗接住，带着一丝不安看了看。

"*她们联合在一起会变强，*"你只对纪子和明美说。"*如果她们给你们添麻烦，别犹豫，马上叫我。同时尽量把她们分开，好吗？哦，还有……纪里香准备了一些反魔法附魔。走之前找她拿一下？*"

"*谢谢，会的，*"明美说，又点了点头。"*需要帮忙的话我们一定开口。*"

"好了！"你微笑着站起身，麻美松开了你的手。"好。沙耶香，能跟我聊两句吗，呃……"

"楼上的书房可以给你们一些隐私，"织莉子微笑着提议。"上楼后左边第三扇门。"

"……可以，"你说。"谢了，织莉子。"

沙耶香跳起身来，笑容或许比平时少了几分张扬。但她上楼时脚步依然轻快，你们俩两级两级地跨上台阶，沿着铺着地毯的楼梯平台闲逛，两旁的灯饰巧妙地嵌在装饰线脚里。

"天呐，这地方*真高级*啊，"沙耶香哼了一声。

"可不是嘛，"你说，找到正确的门推了开来。"进来吧。"

"来了来了，"沙耶香说，跟你走进书房。她的表情微微绷紧。"是关于双子那个……*事情*的吧？"

你忍住了道歉的冲动。你本可以做*更多*来帮沙耶香做好准备，迎接作为魔法少女等待她的一切。她作为朋友站在你身边无比珍贵，但你忍不住想——你是不是应该更努力地劝阻她走这条路。

有时候，你会想自己是不是对自己太苛刻了，或者至少，你对自己的标准比对任何人都高。如果沙耶香犯了你犯的那些错，或者麻美，或者焰……你大概会原谅她们。你*应该*更清楚的，该死。你必须做得更好。你*也许*可以对自己稍微宽容点，但你*必须*努力。

"……嗯，是的，"你说，揉了揉鼻子，环顾书房。这*不是*久臣的书房，那是另一个房间，而且……说起来，这里可能是*织莉子的*。但如果是的话，这里完全没有个人痕迹——没什么特别属于*她*的东西，只是一间陈设华贵的房间。"你感觉怎么样？"

"今天的热门问题啊，"沙耶香吐出一口气，鼓着腮帮子。"我……我不知道。"

"想聊聊吗？"你轻声问。

"已经跟杏子聊过了，"她说。"不过再聊聊也没坏处吧？"

你给了她一个鼓励的微笑，她回以一笑……不算脆弱，也不像平时那么张扬，不像平时那么张狂。但是*真实的*，你觉得，不是为了安慰你硬挤出的假笑。光是这一点就够让人松口气了。

"我就是……"沙耶香颤抖地笑了一声，目光从你身上移开，望向窗外，茫然地盯着雨幕笼罩的见泷原。"我是说，我*知道*的。你*告诉*过我这种事。只是……我还是……那甚至都没真正*阻止*她们，她们现在也没事了，所以——"

"沙耶香，"你温和地说，快步穿过房间走到她身边。"你不需要为自己的反应找理由。特别是这整件事就这么……硬塞到你面前。所以你不需要解释什么，不用对我，也不用对任何人。如果你觉得害怕，那就是害怕，说实话这比我的反应正常多了。"

"但你——"沙耶香摇摇头。"你处理得好好的。*由麻*也处理得好好的。"

"由麻去得晚，而且我很确定杏子帮她挡掉了最糟糕的部分，"你说。"至于我嘛，我本来就不正常，而且——"

"哦，*这个*我早就知道了，"沙耶香插嘴，带着一丝坏笑。

"——*而且*我一直都知道会是什么样，"你说，无视了这次打岔。不过话说回来，她还能自在地开玩笑，这让你挺高兴的。"甚至在我成为魔法少女之前，我就知道，深入骨髓地、*灵魂深处*地知道，最坏的情况会是什么样。所以我有准备，而你……没有。这*完全*不丢人，沙耶香。"

"我知道，只是……"沙耶香叹了口气，一只手揪着自己的头发。"我*知道*这不合逻辑，但……就是*放不下*。不只是……不只是*发生*了什么，而是所有人就那么*处理*了。"

"我们*真的*需要找个心理咨询师来了解这些，"你叹气说。"另外，我现在要抱你了。"

这换来沙耶香一声轻笑，但她*确实*主动走进你张开的怀抱，你的手臂环住她，轻轻一抱。

"我不知道，"她最终开口，一些紧绷感随之消退。"我怀疑心理咨询师会给人拥抱，那他们能有多好？"她表情变得认真起来。"我不知道有没有什么……我觉得我只是需要消化一下。"

嗯。倒是给了你一个想法。

"……你要不要，呃，休个假？"你从拥抱中退开一些看着沙耶香。"我是说，我们会想你的，但如果你需要时间消化，你*完全*可以有这个时间。"

"我……"沙耶香眨眨眼。"还能这样的吗？"

"少了你我们绝对会想的，"你说。"你一直是团队的中流砥柱。但如果你需要时间，我们*是*能撑过去的。我们应该也没什么大仗要打吧，而且……反正净化什么的也不缺人手，你知道的？"

"我考虑考虑，"沙耶香缓缓说，然后笑了。"下次星座联盟开会的时候提一下吧。年假什么的。"

你咧嘴笑了。

"不封顶年假，否则免谈，"你说。

"不封顶年假！"沙耶香附和，举起一只紧握的拳头，然后笑容又渐渐消退。她的目光重新落在窗外。"……你知道吗。我现在明白你和焰为什么那么想让小圆远离这种生活了。我是说，我以前也理解，基本上也认同，但现在我*真的懂了*。我明白你们为什么想阻止*任何人*加入我们，但……我懂了。"

"嗯，"你认同地说，跟她一起望向窗外的见泷原，还在雨中浸泡。你向东望去——东面朝着市中心，朝着见泷原中学。"……不过记住这个。任何时候你需要或者*想*休息，就去休息。跟谁说一声，我们会想办法的。"

"……好的，"沙耶香深吸一口气，微笑着说。"嗯。我……其实，去翌桧市那趟。就是送个东西对吧？所以你不需要我，对吧？"

"哦，嗯，"你眨了眨眼。"说得对。是的，就是送东西，可能跟妮可聊聊？重建她们的身体今天大概搞不定，所以*绝对*可以不去，好好上你的课或者干点别的。"

"好，那就这样吧，"沙耶香缓缓点头，然后又更坚定地点了一次。"这次我就不去了，而且……大概在离开这里之前解除这个分身吧，你帮我保管力量宝石？"

"当然，"你说。"你也可以去见泷原到处跑跑放空一下，随你。"

"说实话，我现在想要一些正常的生活，"沙耶香摇摇头。"不过谢了。"

"随你，"你说。"好了，如果这就定了……对。织莉子想跟我聊聊。"

沙耶香的表情闪过一丝明显的嫌弃，然后变成了一抹淡淡的坏笑。

"要我把她叫上来吗？"她问。"省得你跑一趟。"

"……这是她的家啊，"你说。"这也太不礼貌了吧。"

"重点就是这个，"沙耶香说，披风一甩已经朝门口走去，随意地朝你挥了挥手。"你坐着等就好。"

你叹了口气，靠在桌子上等着。有些仗你得选择性地打，你想，让沙耶香开心一下似乎也没什么大碍，搞不好还能让她心情好点。织莉子会理解的，你希望。你望着窗外，边等边坐立不安，不一会儿，你感觉到两个灵魂宝石在靠近……然后继续越过书房到了隔壁两个房间再折返回来。

"萨布丽娜，"织莉子推开门时说了声招呼。你注意到她胳膊下夹着一个信封——大概是刚去拿的东西。

"嘿嘿，萨布丽娜，"纪里香快活地举手打招呼——另一只手当然牢牢环在织莉子的腰上，两人紧紧黏在一起。"对了，已经把反魔法附魔给那对非双胞胎了。"

你饶有趣味地看着她们试图*进*屋——纪里香完全不愿意放开织莉子。过了一会儿，织莉子侧过身子，这样就能把纪里香拽进来而不用跟她分开。

"嗨，"你说，微笑着从桌边站直。"你们还好吗？"

"挺好的，"织莉子说。"你真的派了美树小姐来叫我？"

"她坚持的，"你叹了口气。"抱歉啊。"

"我没有生气，"织莉子带着淡淡的笑意说。

"谢啦，"你说。"那……你想跟我聊什么？"

"嗯，"织莉子说。她把信封递给你，等你接过后才补充道："我的遗嘱。有见证人签字，律师那里也存了一份。"

你差点把它掉在地上，震惊地盯着她。

"我指定你为第一受益人，"织莉子带着从容的微笑说。"*不过*，我已经决定，我*真的*非常希望这份遗嘱永远不需要被宣读。"

"我也是！"纪里香开朗地补充。"我喜欢活着。"

"我……"你揉了揉额头，试图挡住那个不可能存在的头疼。"好吧，我……好吧。织莉子，你*真的*必须——不，我忘了我在跟谁说话。行吧。"你深吸一口气，然后吐出来。"这是关于你预见到自己死亡的那个预言，对吧？"

"是的，"织莉子说，笑容微微收敛。"我觉得提前做好准备比较稳妥。"她抿了抿嘴。"说实话……我曾经以为自己会满足于和纪里香安安静静地度过最后的日子。但我后来改主意了——我更想*活着*。"

她和纪里香交换了一个温暖而深长的注视，你觉得自己目睹这一幕有些不自在，但那也没能完全抑制住心底那种说不清的背叛感和受伤感。

"你还以为你会死？"你问。你以为自己已经扭转了那种心态。

"我以为自己已经接受了，如果真的发生了，我会坦然面对，"织莉子纠正道。"这两者之间的区别确实很细微，但对我来说很重要。不过这已经是过去式了，因为我现在已经决定，我*非常*希望继续跟纪里香一起活下去。"

"……那我接受，"你说，终于把目光从这对人身上移开，皱眉看着你手里夹着的那个信封。叹了口气，你用悲叹把它包裹起来，旋转着收入锤子空间暂存。"我也*同样*希望你们俩继续幸福地活着。"

织莉子微笑了。

"谢谢，"她说。
