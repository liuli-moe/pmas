# 异常物质 48

你哼了一声，胃里有些发紧。你要做了。你真的要做了。你要对麻美坦白一切。

然后你要祈祷她不会把你推开。

她……对你来说已经变得很重要了。

而且你不确定如果她真的那样做，她是否还能承受得住。

对一个魔法少女来说，当你的**生命**都系于你的情绪——

"萨布丽娜？"麻美碰了碰你的侧身。"你没事吧？"

你呼出一口气。"嗯，"你说，声音平稳。你冲她微笑。"嗯，只是在想事情。"

也算实话。

而且你可以先好好把晚餐做完，不让这件事的阴影笼罩你。

你可以做出一顿完美的晚餐。

"好吧，"麻美微笑着回应。"我们先把东西收好，然后吃晚饭？"

"好，"你点头，挺起肩膀。"给！"你从橱柜里翻出一个搅拌碗，带着温暖的微笑递给麻美。转回桌子，你开始按照存放位置分类整理食材。你花了几分钟把一切都归置整齐。

当你抱着最后一批东西——面粉和其他干货，准备放进橱柜时，麻美对你绽出灿烂的笑容。

你忍不住笑着回应，在经过她身边时转了个小圈。

麻美咯咯笑着，对你行了个屈膝礼，然后将锅放到炉子上。

这并不全是演出来的。你在……压制着内心的不安，但融入日常节奏本身就令人安心。温柔的打趣，轻松的玩笑。

这让人舒适，也让人安心。

麻美几乎是翩然从你身边飘过，脚步轻盈，拆开乌冬的包装。你微笑着，与她完美配合地擦身而过，开始切鸡肉。

你几乎可以压下胃里那翻搅的感觉，那丝恐惧——你可能会失去这一切。

你正好在麻美加完调味料后将切好的鸡肉滑入高汤锅中。她给你一个微笑，侧身让出一点空间让你搅拌，她的手臂轻轻蹭过你的。

"昆布高汤？"你观察着汤色问。一碗清淡的海带高汤再合理不过了，闻起来也确实是。

"嗯嗯！"麻美赞同，接过搅拌的工作。"你去看看面条好不好？我觉得再炖几分钟就可以吃了。"

"好的，"你答应。放下手头的活，你去检查正在锅里欢快翻滚的面条。满意之后，你沥掉水，分到碗里。麻美浇上高汤，你翻找出一些干海苔做点缀。

"搞定！"你对麻美笑着说，从她手中抢过碗端到桌上。

麻美咯咯笑，对这个小游戏已经习以为常。她拿了餐具，你则切了些西瓜做饭后甜点，暂且放在一旁，然后在桌子对面坐下。她给了你一个温暖而满足的微笑。

你回以微笑，一起说了句传统的"我开动了"，便开始吃起来。饭间你们没怎么说话，但这份安静很舒服，此起彼伏的吸面声充满厨房。最后你们用西瓜收尾，两人的叉子叮叮当当地碰在一起，互相推让着要对方多吃点。

终于，你靠在椅背上，麻美也同样放松下来，带着柔和的笑意。"很好吃，"她说。

"嗯，"你赞同，咽了咽口水。"是很好吃。"

麻美当然注意到了。一丝担忧掠过她的脸。"萨布丽娜？怎么了？"

"我……"你开口，迎上她的目光。"麻美，你还记得我说过有些事想要……先想清楚？再告诉你？"

麻美缓缓点头。"我——你不必告诉我，萨布丽娜，如果你不想的话，"她微微缩了缩。"我——你不必说。"

还来得及回头。闭嘴就好。麻美给了你一个台阶。

你的期望悬在线上。

她值得知道真相。

而且你不想让这件事横亘在你们之间。

缓缓地，极其缓慢地，你摇了摇头。你感觉自己在敲响丧钟。"不，"你低语。"你值得知道，麻美。"

她的肩膀塌了下去。"要不……我们移到沙发上去？那样——那样会舒服些。"

"好，"你同意。"可以。我，我——我能不能做个隐私装置？这，这是私密的事，我宁愿……**谁**都不要听到。"

麻美僵硬地点了点头，推开椅子。她伸手去拿碗，你连忙跳起来帮她，移步到水槽边。你和麻美一起洗碗，擦干，放进橱柜，一句话也没多说。也许你花的时间比平时稍微长了一点。

最后，你们挪到了沙发上。麻美蜷在你身边，焦虑不安。你隔着窗户召来一团悲叹，低下头将你的意志灌注其中。**阻隔。让我与麻美的对话隐私化，任何人，甚至孵化者，都不得知晓。**

你的视线恢复清明时，手中握着一条微微发光的白色环带，中央镶着一颗金色宝石。它安装在一个小底座上，既然似乎就是这个用途，你将它放在桌上，确信你们的对话将不受任何窥听之耳、之眼以及任何其他形式的窃听。

麻美看着这一切，沉默地蜷在你肩上，寂静不断延伸。

当你再也忍不住时，你开了口。"我……我相信你也注意到了，麻美，但……我知道的那些东西不**正常**。我了解魔法少女的体系，还有各种语言。失忆症不是这样运作的。"

"也——也许只是魔法之类的，也许你——我——某个魔法少女攻击了你？"麻美摇着头说。"我——我不在乎这些，萨布丽娜。"

你呼出一口气。"我知道，"你低语。"我也不知道。我没法告诉你我怎么知道的，因为我**不知道**。"这是实话。你……确实不知道。"但不只是这些。我知道的远不止这些。"

麻美握紧了你的手臂。她什么都没说。

你也没有看她。你继续说下去。"我在那条巷子里醒来的时候，我就知道了很多事。"你舔了舔嘴唇。"关于少数几个人。焰、小圆、沙耶香。还有其他的事。其他的人。"麻美的手指收紧，掐进你的手臂。"所有这些人，所有这些事都很重要，值得说出来。"

为什么这么难说出口？

你鼓起勇气。"我知道关于你的事，"你耳语。

麻美发出一声细小的、哽咽的声音。她紧攥你手臂的手指丝毫没有松开。

"我，我——"你结巴起来。"我知道**关于**你的事，我——我不**了解**你本人。而且也不是所有事，我，我——"

"你——你——"麻美摇着头，泪水从眼角挤出。"不——不，不——不要你也——"

"不，"你耳语。"不，我——"你伸手握住她的手。

她在发抖。她的手冰冷刺骨，手指掐进你的前臂。

"我不是，"你耳语。"我不是。我——我不**了解**你。我不——我不像它。我根本不知道**你这个人**，我根本不知道你什么都会做，不知道你在弓道社不知道你喜欢玩游戏。"你在语无伦次了。你强迫自己颤抖着吸了一口气。"我不知道我们能相处得这么好。我——我不知道我们能成为**朋友**。"

"朋——朋友，"麻美耳语着。泪水流过她的脸颊，呼吸在喉咙里断断续续地梗塞。"我——我——萨——萨布丽娜——你——丘——丘比——我——"

她的灵魂宝石。你能感觉到它在搏动，不断被填充。悲叹急剧涌上，逼近一半的刻度。

太危险了。

你抬起手，轻轻覆上麻美的手。她猛地一缩，手在颤抖。

你抽出手来，拽出一道悲叹之河。

麻美发出又一声哽咽的、恐惧的声音。

金光绽放。你一惊，什么东西撞上你的侧身然后你在**坠落**——

等你落到地板时，你已经被金色缎带牢牢裹成了一个茧。你的双臂被夹在身侧，而麻美——

麻美摇摇晃晃地站起来。她已经变身了，身体晃动着，眼睛瞪得大大的，眼白全部暴露。癫狂、凝视、**恐惧**。

她的双手空无一物。

她勉强迈出一步。朝窗户的方向。她的目光没有离开你。

然后她停住了，前后摇晃。她跪倒在地。

一声嚎啕的哭泣。她跪趴着，连滚带爬地回到你身边，用发抖的双手粗暴地抓住你。她把你紧紧抱住，像抱着一个巨大的靠垫。

"为——为什么，"她耳语着，用力摇了摇你。"为什么？为——为什么——你——你——为什么？"

- [x] 而且，我们知道的关于她的一些事是私密的。我们知道她许愿的背景，虽然不知道确切的措辞。我们知道她需要一个朋友……所以当她提出让我们同住时，我们答应了。

- [x] 让她消化这些。
- [x] 如果她愿意让你继续说，解释为什么没有早点告诉她。起初是因为你在巷子里醒来后还在适应状况，而且……这一切实在太不可思议了。然后有好几天根本就没有**时间**，在她发现丘比一直在欺骗她之后，她那么受伤，你不忍心雪上加霜。而且很容易就这样一直不说，因为到最后，当丘比不再碍事、你本来**可以**腾出时间告诉她的时候，你之所以让自己一拖再拖，真正的原因是你害怕——如果你告诉她，她就不会让你留下了。而……你不想离开。你想留下来。你**想要**留下来。
- [x] 低着头，自我谴责。你还是应该早点告诉她的。
- [x] 如果气氛允许的话，告诉她——我们和她住在一起不只是因为她需要朋友，而是因为在真正了解她的过程中，我们发现她是我们所能期望的一切，甚至**更多**。当然，因为她需要朋友，这也是原因。
