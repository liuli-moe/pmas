# 危险课程 37

剧透：投票结果

- [x] 是的
- [x] 要随意一点。
- [x] 还有些事我想告诉你，在其他人面前我还没准备好说
- [x] 焰说过，上一个循环里小圆许的愿望是"希望一切能被修好"。
  - [x] 焰似乎认为我的存在跟那个愿望有关。
  - [x] 很多按理说我们不可能插手帮忙的事都变成了可能。我一直认为是她的愿望在暗中帮助我们。
- [x] 我们打败织莉子的时候，她说她做的这一切都是为了确保我和焰联手，因为"你们在一起就能改变命运"。
  - [x] 如果羽翼是焰的愿望独自运作，它可能在保护焰的主动权。也许我能改变事情，但需要焰来"锁定"改变。
- [x] 把隐私结界收进锤子空间以防午餐时用到。

冷静，萨布丽娜，冷静。要随意。

"没错！"你爽朗地说。

完美。

然后你一把将麻美拉到你的腿上，紧紧地、*紧紧地*抱住她。你发现笑声不由自主地从喉间涌出，明亮、欢喜、完全无法*停止*，因为麻美*猜到了*。因为这是你一直守着的倒数第二个秘密，因为麻美猜到了，那就意味着你们可以*讨论*它了。

因为你再信任不过她来知道这个秘密。因为你爱的这个女孩是彻底的、完完全全的*天才*。而且因为*你不再孤单了*。你有了一个可以谈论它的人，一个理解你的人，一个*真正*理解你在为什么而战的人，一个跟你完全站在同一边的人。

麻美对你灿烂地笑着，她自己的咯咯笑几乎融化在你怀里。她的脸上只有理解，蜜金色的眼睛里是深深的*接受*，她笑着看着你。

花了你好几分钟才平静下来，你轻轻地用额头抵住她的额头，闭上了眼睛。

"你呀，我亲爱的、甜蜜的麻美，是个天才，"你喃喃说。"对。就是她们。"

"任何了解你的人从那个故事里都猜得出来，"她轻声说。"任何*看过*你跟焰和小圆相处方式的人。"

"也许吧，但*你*才是真正*做到*的那个人，"你说。"你才是此刻在我身边的那个人。我一直*好害怕*……既害怕保守秘密可能带来的伤害，又同样害怕*泄露*秘密可能带来的伤害。你自己想明白了，麻美，而这……意味着一切。"

"嗯，"麻美说着身体微微后靠。你的眼睛刚好睁开，就看到她若有所思地端详着你的脸，然后她笑了，柔和而璀璨。"你知道你很了不起吗？"

"我别无选择，"你轻声辩驳。"我做不到不管。"

"我知道，"她说着笑容不减。"所以你才了不起。"

你哼了一声。

"这个辩论我赢不了吧？"你问。

"当然赢不了，"她说。

"好吧……行，"你咧嘴笑了。"那我换个话题。有些……细节我想告诉你，既然*你*已经知道了。"

麻美凝视了你好一会儿，再次端详你的脸，似乎想从你的表情中读出什么秘密。但只是片刻，一个愉悦的微笑便如阳光穿云般绽放在她脸上，照亮了她的表情。

"你值得所有的赞美，甚至更多，萨布丽娜，"她说。"我得让你慢慢习惯才行。不过好的，请说？"

"我——这*不公平*，"你哀嚎。

"我知道，"麻美笑盈盈地说。"本来就不是公平的，就像你赢不了那个你不够了不起的辩论一样。"

"好吧……行，"你说。深吸一口气，你对麻美微笑，努力把你绝对没有的红晕赶走。"你对这一切都还好吗？"

"当然还好，"她说着笑容稍稍收敛了些。"想到这一切可能发生——或者*已经*发生了，然后就像*我们*可能被抹消一样被撤销——确实很可怕。但那是焰和小圆，而且……我认识她们。我认识*你*，萨布丽娜。我完全相信我们会想出办法的。而且如果最坏的情况发生了……"

她的笑容完全消失了，即便如此她捧起了你的脸，手指温热地贴着你的脸颊。

"如果最坏的情况发生了，你会在下一个世界找到我的，"她说。

"不会——"

麻美一根手指按住你的嘴唇，笑容重新浮现。

"不会走到那一步的，"她说。"我知道不会。"

"好，"你低声而坚定地说。"这是为了焰，为了小圆。为了*你*。为了沙耶香、杏子、由麻、渚、和美，还有……我们认识的所有人。"你把手覆在她的手上，轻轻握紧。"这个世界有太多值得为之奋斗、值得珍惜的东西，而且*我们*不会让它从我们手中被夺走。"

"不会的，"麻美表示赞同，回握了你的手。

你微笑着，享受这份宁静的亲密和那种深入骨髓的安心——知道麻美理解了，*真正*理解了，而且你们两人在信念和目标上完全一致。你唯一隐隐担忧的是你仍在对她保守的最后一个秘密：魔女的起源。那个你真正害怕可能会击溃麻美的秘密。

你内心有一部分觉得应该揭掉最后一块创可贴告诉麻美。而且你担心麻美可能会自己想明白，因为她已经拼齐了几乎所有的碎片。她知道小圆。她知道小圆许了什么愿。你那多疑的一部分担心，从那到作为魔法少女的最黑暗真相只是一小步之遥。

但你信任麻美，你*了解*麻美。如果她真的自己想明白了，她会来找你。*你*是她的锚，就像她是你的锚一样。她会来找*你*，而你会陪她度过。不是最理想的情况，但你了解她，你信任她，你会在她身边。

同样的道理，你觉得你也可以主动告诉她，然后陪她消化。也许在可控的环境下说出来会更好。你一直在让事情变好，你一直在推进逆魔女化的研究，在*修复*已经造成的伤害。都是有力的论据，但你就是……害怕伤害麻美。

那跟她的恐惧是同一类型的恐惧。你*会*帮助焰和小圆的，你*会*解决天堂之战的。世界*不会*被重写。你*会*陪麻美度过巫妖炸弹的冲击，她*会*从痛苦和伤害中痊愈。

但是。*但是*。你无法压制那个非理性的恐惧，那个低语着的*万一呢*？

所以现在不行。你会鼓起勇气，然后……也许你会找到合适的时机。但不是现在。

"……所以，"你片刻后说。"我想我之前跟你提过，焰说过上一个循环里小圆许的愿望是'希望一切能被修好'。而且焰觉得我的存在跟那个愿望有关，然后……是啊。"

"这就解释了为什么你……在之前的时间线里不会存在，"麻美说着伸手握住你的手，轻轻一握。

"对，"你叹着气说。

"嗯，"她若有所思地说。"那这是不是意味着我在跟女神的女儿约会？"

*这*让你忍不住笑了出来。

"*而且*某种意义上也是恶魔的？"你说。"虽然……这也太奇怪了，而且真说出口也太自恋了。鹤屋小姐说得对。"

"嗯，你*确实*是天使啊，"麻美说着笑容重现，然后变成了困惑。"……双子*知道*？"

"……我……老实说不知道她们是怎么回事，"你承认。"她们，呃。真的很奇怪，哪怕以我的标准来看也是，而且……我*确实*知道她们的事，但她们跟我的知识不一样，所以我真说不好。"

"啊，好吧。"麻美点头。"不过……好。那如果你*确实*是被小圆的愿望创造出来的，有什么含义？"

"*大概*就是为什么我有一个不可能的力量？"你说。"而且就是……很多按理说不可能的事我们都*能*插手帮忙？我一直认为是，嗯，小圆的愿望在暗中帮我们。"

"……比如双子？"麻美说。

"我觉得是的，"你说。"也可能只是因为我对她们的了解更模糊，因为她们的故事跟焰和小圆的交集不多。不过……说到故事。"

你抿了一下嘴唇，花了片刻时间整理下一个要说的点。

"织莉子。当我们打败她的时候，她说她做的这一切都是为了确保我和焰联手合作，因为'你们在一起能改变命运'，"你说。"我不确定这里面有多少是她在忽悠。我信任她，但……我是说，你了解她嘛，对吧？她有点……"

"戏剧化，"麻美提供了一个词。

"戏剧化，对，就这个词。我只想说，纪里香*绝对*是她的好女友，"你咧嘴笑着用手遮住一只眼比划纪里香的眼罩。"总之。重点是，前半部分关于和焰合作的事？我觉得那本来也会发生的，就算没有织莉子来*推动*。但另一部分嘛……"

"……以我现在知道的，我……能理解那是怎么运作的，"麻美说。"就是你对鹤屋小姐暗示的'锁定'改变那回事。"

"对，"你说。"如果羽翼是焰的愿望在独自运作的话，它可能在……我不知道，试图保护她的主动权？试图塑造事件走向，走向催生了那个愿望*本身*的轨迹？"你皱了皱眉。"我不喜欢这个措辞，给它赋予了太多能动性。应该说是惯性吧。本体论惯性，引导着事物。"

"我明白你的意思了，"麻美皱着眉说。

你张口想继续说，然后慢慢闭上了嘴。麻美的表情有一丝走神，那种正在推演一个想法的样子，所以你忍住了让她想完。

"……焰的愿望，是的，"麻美说。"但小圆的呢？不是最近的这个。循环之理。*那个*是不是让干预成为可能的东西？小圆的愿望给了失去引导的循环之理一个任务？"

"嗯。也许，"你说。"听起来有道理，但……暂时有点无法证明？"

"确实，"麻美说。"但我觉得这里面还有*第三*块拼图？如果跟焰合作可能可以改变命运之类的，那……*小圆*呢？"

你眨了眨眼。

"我……不知道，"你承认。"但你说得对。我一直以为她在这件事中的角色是……"你含糊地挥了挥手。"后援吧，既然她不是魔法少女。但你说得对。这毕竟关乎小圆和焰*在一起*，而且……可能需要我们三个人才能让持久的改变落地？我不确定。我得想想。"

"她不必身处危险中，但她*确实*是这一切的一部分，"麻美沉吟道。

"对，而且……"你皱眉。"说实话这个问题我一直在纠结。我不确定该怎么调和它跟焰想让小圆远离危险的心愿。"

"让她参与到建设更美好世界中来，"她喃喃说着，皱眉跟你一样陷入思考。"这不就是你一直在做的事吗？"

"对，"你说。"但我一直担心这还不够。"

"那我也会好好想想的，"麻美点头说。"看看我能不能制造一些机会。"

"谢谢你，"你感激地对麻美笑着，再次拥住她。

"当然了，萨布丽娜，"她温暖地说。

你们两个都享受了片刻的亲近和温暖，然后默契地拉开距离，相视一笑。

"我们大概不该让朋友们等太久了，"麻美说。"不过还有*一件*事——我怀疑鹤屋小姐已经知道焰是你故事里的其中一个女孩了。大概猜不出小圆，但焰的话……从你跟她相处的方式来看就太明显了。*而且*焰有时间魔法。"

你不高兴地皱了皱脸。

"你可能说得对，"你说。

"我觉得从你把故事透露给她的那一刻起，这就是不可避免的结果，"麻美说。"但是……"她咬了咬嘴唇。"你一定要尽量避免让鹤屋小姐太多地观察你、焰和*小圆*三个人的互动。她很敏锐，而那个逻辑推理并不难做出。"

"……啊，"你说。

说实话你倒不太*介意*有希知道。她做事从来不遮遮掩掩，对自己想要什么、打算做什么坦诚布公，这一点你可以信赖。

但焰会介意。

"对。你说得对，"你说。你深吸一口气，点头。"好。那么……如果没有别的事，该出发了？"

"没了，我觉得我的好奇心和顾虑暂时都解决了，"麻美说着从你腿上挪开时微笑。"想到什么的话我会跟你说的。"
