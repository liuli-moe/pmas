# 护送 10

剧透：投票结果

- [x] 你打算对鹿儿岛的女孩们采取什么样的初步策略？
  - [x] 她们看起来是一个合理友善的组，位于日本相对偏远的角落——一个不错的锚点，可以从那里向外辐射，为更多人提供净化。
    - [x] 不掩饰另一个悲叹控制者的存在（可以交流技术）以及获得即将到来的魔女之夜战斗援助也是动机之一，但纯粹想要帮助别人才是首要目标——言行一致地将此作为讨论重点。
    - [x] 如果有必要的话，给出常规免责声明——你的帮助绝不以对方帮忙打魔女之夜为条件等等，但最好不要一上来就把重点放在这方面。

你想要什么呢。你有点想直接开门见山说魔女之夜的事。对很多人来说，那是最需要知道的事情，那种笼罩在所有其他对话之上的大阴影——即使对你来说，她也不是你会轻视的存在，而且你觉得自己的胜算……*还算*有把握。以此开场是坦诚的做法，表明你的诚意，你没有试图隐瞒什么重要的事，但同时，魔女之女王这种话题会笼罩并且*渲染*你们可能进行的每一次对话。

"我想帮忙，"你简单地说，用另一个同样震撼但方向不同的东西来开场。"我……确实能免费净化灵魂宝石，我*确实*想提供帮助，如果需要的话。我希望建立联络网，这样我可以把消息传出去，也让消息能*传到*我这里，如果有人需要帮助的话。而且我确实很想跟另一个悲叹控制者聊聊技术。我从没见过跟我有类似能力的同行。"

真子跟加里奈交换了一个眼神。她们之前就听说过你，你知道——她们在 IRC 上提到过。通过口口相传，一个福岛朋友的朋友的朋友。她们可能已经知道了星座联盟的事，取决于那个朋友传了多少，她们也可能已经知道了你对爱荷华组做了什么。

"不过……"你揉了揉脸，皱了皱眉。"我……也听说过两个悲叹控制者碰面会很不愉快？我不知道那只是刻板印象还是什么，但不管怎样，如果，呃，初见小姐？不太想见我，或者就是不想见，那完全没问题。我不会介意的。"

"我明白了，"真子说，声音平稳。她的日语带着口音，尽管她显然在努力咬字清晰——你觉得在见泷原或东京的居民看来应该算是乡下口音吧。但对你来说只是悦耳的圆润语调。她张了张嘴，又闭上，犹豫了一下，目光飘向加里奈手中的蛋糕盒，叹了口气摇了摇头。"啊，管它呢。"

"抱歉，"你尴尬地笑了笑。

"呃——不不，我不是说你，"真子用力摇了摇头，橙色头发甩得到处飞。"只是……我们真没想到这些，虽然我们确实发了邀请。呃。我们很高兴你来访，薇小姐，巴小姐，美树小姐。而且我们很乐意更深入地讨论。"

"完全没关系，"麻美安抚地笑着看了你一眼说。"我们理解。"

"嗯……"你说着，努力不让自己萎靡下去。"如果说的太多了，抱歉。我知道我有时候会很多……我在尽量控制？"

沙耶香忍住了一声嗤笑，显然在忍住不在陌生人面前损你，但你从她目光瞥向你的方式看得出来她在*想*。而且声很大。

"不不，"真子摆着手说。"不是你的错，薇小姐，完全不是。嗯，请别伤心？"她跟加里奈交换了一个半恐慌的眼神，然后深吸一口气挺直了身子。"你们愿意去我们的活动室坐坐吗？我们，呃，得小心别被老师看到，但那……呃，希望不是问题？"

"听起来很好，"麻美说着给了你一个好笑的小微笑，挽住你的胳膊。"萨布丽娜可是有丰富的偷偷潜入学校的经验呢。"

"到时候你们得给我们讲讲，"真子说，一个腼腆的笑容终于透过那副僵硬正式的外表浮现出来，开始放松了，转身从屋顶边缘跳下去领路。

穿越鹿儿岛市的屋顶没走多久——毕竟这座城市不*那么*大，建筑更矮更分散。但天气很好，天空澄澈蔚蓝，樱岛那郁郁葱葱的山坡构成一幅惊艳的天际线背景。你们很快到达她们的学校，又是一座玻璃钢铁和光的组合，不像见泷原中学那样精致繁复，更偏向于向横向延展而非纵向耸立，但……还是有着同样那种隐约令人不安的新文艺复兴风格。话说回来，学校嘛都那样。

"天台！"加里奈喊道。她深蓝色的头发色彩鲜艳，在你们小队伍的前方飘动，金色镶边的环形图案在风中流动，引人注目。

不管到哪里有些东西都是一样的，你暗自想——但话又说回来，你也没有去调查不同国家甚至日本各地的学校。也许有宽阔开放天台和便捷通道这件事是一种*城市*特有的现象。也许在某个时间点甚至是某个愿望造成的，将它铭刻进了流行做法之中。

不管怎样，你们五人稳稳着陆，然后走下楼梯，加里奈和真子在前面带路仔细倾听着。你本可以展开悲叹雾来探路，感知前方有没有老师或学生，但那似乎太高调了，所以你就让她们引路，带你到一条走廊尽头的一扇门前，上面贴着一张手绘的牌子，自豪地宣称这是"超自然调查社"。

"我们当然*没有*在撒谎说我们做的事情嘛，对吧？"真子在看到你的目光停留时露出短暂的笑容说。"请进。"

超自然调查社的活动室是个局促而温馨的小空间，有一扇不太亮堂的窗户、一台看起来很古老的电脑放在一张桌上，一面墙被书架和沙发占据了。墙上挂了几张恐怖电影海报，但有一面墙完全被一个软木板上的放大版城市地图占满了，由几十张 A4 纸整齐地钉在一起组成。地图上散布着各种颜色的小图钉，你忍不住注意到它们聚集在办公楼和医院周围。

"那些是……魔女出没的位置？"沙耶香好奇地问。

"超自然目击记录，"加里奈一本正经地说。"搜集这类传闻并调查它们，当然是我们的职责。"

"*聪明*，"沙耶香笑着说。

"我会告诉和的，让她知道你这么说的，"加里奈微笑着说。"这是她的主意。不过我们别在门外站着了，虽然时间比较晚了，但还是有老师和其他学生在的。"

你们全都挤了进去，真子招呼你们三人坐沙发，自己忙着切蛋糕，拿出一些纸盘子来分装。加里奈的目光追随着她的动作，看着那些色彩缤纷的小蛋糕，带着那种来自怀旧的渴望。

"很遗憾我们这里没有冰箱也没有水壶，所以只能提供矿泉水，或者……"真子翻找了一下，拿出三个瓶子，皱了皱眉。"或者常温汽水，你们要不？"

"水就好，谢谢，"麻美替你们三个挤在沙发上的人回答了。

"嗯，不怪你们，"真子闪过一个短暂的笑容，拧开一瓶水。"那就水吧。"

"那……薇小姐，巴小姐，美树小姐，你们说是来建立联系的？"加里奈小心地问，一边庄重地从你带来的各式蛋糕中切下第一片。

这是很有礼貌地在提示你接着之前的话题。你快速跟麻美、再跟沙耶香交换了一个眼神。麻美只是给你一个鼓励的微笑，而沙耶香翻了个白眼，忙着接过一片递来的蛋糕。

你忍不住注意到她们几乎没有提到自己缺席的两个成员——其中一个就是和。初见和，她们的悲叹控制者。你想起了焰之前告诉你的：她似乎对过去的某件事感到悔恨，内疚驱使着她。如果你说服她加入，她会说服她的朋友们。

你不打算那么做。焰在同一次对话中还告诉你，园真子的魔法在对抗魔女之夜时会很有用，你当然会试着邀请她。只是……不是通过让某个成员产生愧疚来达目的。但这仍然是你想要记在心里的东西，它如何塑造她们的关系和动态。你在这里就能看出来了——她们小心翼翼地让和远离视线，无论是字面意义上还是比喻意义上。出于保护，你觉得，因为她是*她们的人*，而*那个*你再理解不过了。

"那……有两件事我想先提一下，因为它们都挺重要的，"你慢慢说，没有说出那些想法。"第一件事是因为……嗯，我知道你们听说过我的魔法，但听说和亲眼看到不是一回事。所以……你们想看个演示吗？"

"好啊？"真子慢慢点头，栖在电脑桌边，带着不易察觉的紧张看着你。

你转向麻美，发现她已经在朝你微笑了，脸上带着一个俏皮的笑容，伸手取出灵魂宝石。她展开掌心让真子和加里奈看，手指松松环住那颗五瓣宝石——*她*的灵魂——蜜金色的深处刚好可以看到最细微的悲叹光泽。

足以被看到，也足以在你弯弯手指将其引出时显而易见，化为一小珠悲叹悬浮在你掌心上。足以让真子和加里奈的目光追随着它，被那专注的、沉重的、不移的注视力牢牢锁定，你尴尬地朝她们笑了笑。

片刻之后她们同时叹了口气，移开目光对视了很久很久，无声的交流延续了一会儿。而确实是无声的，一场情感的风暴完全通过她们目光交汇的方式传递，没有一丝抽动暗示她们可能在用心灵感应*说话*。加里奈靠回电脑椅上，真子试图但没能掩饰住一个矛盾的表情。

"那可真够厉害的，"真子嘟囔着，口音更浓了。

"嗯……嗯，我知道，"你喝了口水来掩饰你确信是明显到不行的窘迫。"但就像我说的，这是我想先提的，因为它……很重要。我只是……我想帮忙，而且因为我的能力，我不受其他人面临的那些限制。"

"我们听说了，是的，"真子半对自己半对你嘟囔着。她用手捋了捋蓬乱的橙色头发，显然在思考。"不过……听说跟*亲眼看到*是两回事嘛。"

"所以。嗯，"你说。"这就是我的出发点。我想*帮忙*，而且……"你顿了顿，然后不太情愿地补充道，"我*绝对*负担得起帮忙，你知道的？"

如果人们能简单地相信你说的——你是来帮忙的，你生活在一个人们会仅仅因为应该而互相帮助的世界里，那该多好。但你不是。此时此刻，说你想帮忙是因为你*负担得起*帮忙，然后证明这一点，更容易让人相信。

麻美当然注意到了你的思路，握住你的手轻轻按了按。你感激地回以微笑，强迫自己放松，等待真子和加里奈整理她们的思绪。

"我相信你，"真子沉默了好一会儿后说。"或者……我相信你想帮忙。但你提到了……两件事要先说的？"

"嗯……"你叹了口气。"第二件不是关于我的魔法，只是一些情况，而且……好吧，行。如果你不介意的话，我想在说之前先说一下我*为什么*要说？"

"免责声明？"加里奈干巴巴地看着你问。

"……嗯，差不多，"你说着皱了皱脸，又喝了口水。"我想说是因为这是正确的做法——或者说，在最后一刻才告诉你们是绝对不对的。这种事情我觉得*隐瞒*是不公平的，但同时如果你们决定完全不想掺和这件事，那也*完全没问题*，不会影响其他任何事。没有义务什么的，只是……恳请你们听我说完？"

真子打量了你一番。

"你说的那样子，听起来像是你是黑道什么的，"她谨慎地说。"不过我们听你说。"

"说实话，那个*比喻*倒还不差，"你说。"不过，呃，绝对不是黑道之类的。但*确实*是那种'你应该知道你在跟什么打交道'的事情。"你吸了口气。"你们听说过魔女之夜吗？"

"没有？"真子说着看了看加里奈，后者耸了耸肩。

你眨了眨眼，转向麻美。

"这确实不算常识，"她回答，摇了摇头。"是……那种偶尔出现的故事，在魔法少女们真的互相交流的时候。"

"啊，"你不好意思地说。你转回真子和加里奈，表情变得更加严肃。"嗯……魔女之夜是一只非常强大的魔女，强大到能脱离结界存在，强大到能摧毁整座城市。它就是……出现，毁灭一切，然后消失。"

"然后你知道它下次在哪出现呗，"真子试探着说，半是提问半是陈述。从她的表情来看，你怀疑她已经猜到答案了。

"对，"你说。"见泷原。"

"嗯，"真子跟加里奈又闪电般地交换了一个眼神。"我能理解为什么那……嗯。好吧。"

"如果你们需要的话，慢慢想？"你说。"我不会要求你们现在就对魔女之夜本身做任何决定，而且我想说清楚，*不管*你们怎么决定，我认为其他所有事情都是独立的。如果你们决定接受我们的任何提议，或者决定让我们在这里设个联络点帮忙，那完全不以你们关于魔女之夜的决定为前提。"

"但你*确实*想招募我们，"加里奈说。

"我会保护我的家园和我爱的人，"你毫不犹豫地直视她的眼睛说。"这意味着动用我能调动的一切和每一个人。但我*同样*相信我是来*帮助*的，我*永远*不会胁迫任何人参战，无论是武力还是扣留援助。"

加里奈是第一个移开目光的，她偏红的粉色眼瞳从你的视线上落到盘子里的蛋糕屑上。

"可以理解，"她说。

真子深吸了一口气。

"谢谢你跟我们说实话，"她说。"我们……我们会内部讨论一下，在你们走之前给个答复，如果可以的话？我们也会听你们的其他提议，不过要在做了那个决定之后。"

"当然，"你说着忍住了想说那个明显的笑话的冲动。从沙耶香头微微朝你转过来的样子看，她也想到了同一个笑话，但你们都成功地控制住了。"不用着急，说真的。甚至不一定要今天——我们的帮助邀请会一直有效的，我们也随时乐意再来。"

"与此同时……你说过想见和？"加里奈用一种谨慎而克制的语气问。"我们想先内部讨论一下，然后……她说她愿意抽几分钟来，呃，交流技术。"

你笑了。

"那太好了！就像我说的，我以前从没见过跟我能力相似的人。而且……"你咬了咬嘴唇，想了想。"我保证不会对她动用我的魔法？我知道我们悲叹控制者有那个……名声。"

"……我们很感谢这个保证，"加里奈略有迟疑后说。"你说的没错，那个名声*确实*存在。不过悲叹控制者还有一个名声，就是……不太好相处，而你一直都彬彬有礼、坦诚相待，薇小姐。"

"刻板印象就是*刻板印象*嘛，"麻美淡淡一笑补充道。"在大概轮廓之外很少准确，通常干脆就是错的。我确信初见小姐是个好人，你们这么愿意保护她就说明了一切，而萨布丽娜当然也是。"

加里奈看了真子一眼，真子苦着脸微微点了点头。

"不只是那个，"加里奈叹了口气说。"不*仅仅*是那个。我觉得你是好人。只是——我们不会把朋友的事情到处说。但和她有——你就小心点，行吗？想想她在 IRC 上说过的那些话。"

她低头看着自己的空盘子，开始切更多蛋糕，眉头紧锁。

"总之，"她说。"她们在过来了。和还有柚人。"

"……如果……"你犹豫了一下才继续。"如果你有理由担心我们见面会出问题的话，那真的完全没必要勉强。我不是带着一张要求清单来的嘛。我来是因为想交朋友。"

加里奈坚定地从你手中抽走你的盘子。

"我们又不是什么要小心翼翼对待的乡巴佬，"她尖锐地说着又啪了一片蛋糕到你盘子上塞了回来。"和她是害怕，薇小姐，但她还是想见你。请你尊重她的决定。"

"啊，"你说。"好。"

你跟麻美交换了一个眼神，她只是安心地朝你微笑着接过自己的新一片蛋糕。她相信你，她用微微歪头和更深的微笑无声地告诉了你。沙耶香在麻美另一边又翻了个白眼——对事态的发展一点都不担心，甚至有点无聊。

你发现自己在思索加里奈刚才的措辞，话题转向了更轻松的方向，讨论蛋糕和咖啡馆。原来加里奈小时候跟姑姑去过一次见泷原，有机会在那家店吃过蛋糕，从此就一直心心念念。麻美加入了烘焙建议和如何自己尝试复刻蛋糕的想法，对话从那里开始变得更加顺畅了。

即便如此……

*害怕*。

想想她在 IRC 上说过的话，虽然说实话没什么太多的。但你记得一个胆怯紧张的人说的[那些话](https://forums.sufficientvelocity.com/threads/puella-magi-adfligo-systema.2538/page-6004#post-12199647)，*害怕*你。或者也许是害怕你的*概念*。[那一次](https://forums.sufficientvelocity.com/threads/puella-magi-adfligo-systema.2538/page-6234#post-13233572)你提到跟东京议会见面时她似乎也很害怕。害怕……某个权威降下惩罚……

……因为她用自己的能力做过的某件事。而焰说她也是一个被内疚驱使的人。

……你不禁好奇什么样的境遇和愿望会赋予和这样的能力。你知道*你*是怎么得到你的魔法的，但你很清楚你远不是一个正常的案例。

而现在你想到了，也许她想跟你聊恰恰是*因为*她觉得你可能是那个来审判她的人。那种自我鞭笞的内疚并不罕见，而且几乎可以肯定就是焰提到的那种内疚转化为赎罪。

好吧，她不会从你这里得到那种东西的。说到这个，那应该就是她了。

你不是唯一注意到又有两个魔法少女到来的人——你们五个都注意到了。麻美紧张了最短暂的一瞬然后流畅地继续着对话，阐述着蒸汽烘焙对提升蛋糕湿润度的妙处。沙耶香的头微微朝天花板方向抽动了一下，仿佛在试图看到新来的人可能在哪里。

你感觉到一丝幽灵般的触碰，轻如鸿毛的、胆怯的脚步踏在你感知的边缘。一个魔法少女，是的，跟她身旁的同伴一样，跟麻美、沙耶香或任何其他魔法少女一样：一场束缚着的魔法风暴，意志、生命和*灵魂*化为人形。但你*超越*了这一切感知到了她。即使你瞎了、聋了、你的魔法感知被切断了……你也会知道她在接近。

嗯。

不过，现在不太重要。你让它过去了。

加里奈拿出了笔记本，疯狂地做着笔记，听你的建议，真子则饶有兴致地趴在她肩后看。

你一边加入自己的建议一边追踪着那两个新来的人。两人穿过学校，走的是真子之前带你们来活动室的同一条路线，最终停在了门外，显然在给自己做心理建设。或者也许只是和在给自己打气，你们五个在房间里继续讨论烘焙，礼貌地假装不知道她们在门外。

门终于开了，露出两个穿着跟真子和加里奈同款校服的女孩。你从看到她们就能猜出谁是谁：柚人，灰金发色、体格结实，推开门。和，瘦长纤弱，褪色蓝发扎成马尾，深色的眼睛锁定在你身上。

你没有开口，让她先说，而且似乎其他人也都倾向于如此。

"……你好，"柚人在沉默片刻后说。她轻轻推了一下和，让她进到房间里，笨拙地关上了身后的门。"我是飞驒柚人。"

"我、我是和！嗯，初见和！"和吓了一跳似地开口说话。她深深地鞠了一个九十度的大躬。"请多关照！"

"请多关照，"你笑着伸出手说。"我是薇萨布丽娜，这些是我的朋友，巴麻美和美树沙耶香。"

"是、是的！很高兴认识！"和说完后意识到重复了，缩了缩。"嗯，对不起。"

你尽量不跟着她一起缩。她很紧张，这一点一目了然，缩着身子试图让自己占据尽量少的空间。虽然公平地说，一部分原因是这个活动室挤七个人确实太小了，*而且*她正处于那个四肢过长、在自己的空间里都不太自在的青春期阶段。

"我不会伤害你的，初见小姐，"你温柔地说。

她咽了一下口水，然后用力点头。

"嗯！"她说。"你想跟我聊？"
